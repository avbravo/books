
# Developer Book
El sistema permite cambiar los diseños del login

Este libro muestra la arquitectura conque fue construido el proyecto.

## Acreditation
- Gestiona las acreditaciones del sistema
- Contiene microservicios protegidos

* appconfiguration: Contiene los roles por applicacion se invoca desde el login
* appmoduleconfiguration: Contiene los roles con las autorizaciones para ser usadas en cada modulo y evento que se requiera.
* role: roles disponibles

## SFT
- Utiliza Microprofile RestClient con seguridad

## POA
El sistema esta asociado a un POA basico con la finalidad de que los jefes de departamento creen anualmente las actividades y asi los colaboradores cuando registren sus tareas lo asignen a estas actividades.
Las autoridades pueden ingresar al POA y ver los trabajos que se van realizando en base a los objetivos estipulados.

# Login

Para el login desde una aplicación cliente debemos realizar los siguientes:

Para gestionar el login de las aplicaciones se debe tener almacenado en el archivo microprofile-config.properties **idapplicative**
```xml
idapplicative =6

```
Que representa la coleccion **applicative**

```json

{
  "_id" : ObjectId("61f1a53b8dd7dd1a39e989b4"),
  "active" : true,
  "applicative" : "Sistema de Flujo de Trabajo",
  "description" : "Sistema de Flujo de Trabajo",
  "idapplicative" : NumberLong(6),
  "image" : "",
  "path" : "/sft",
  "shortname" : "SFT"
}

```



Se debe consultar la coleccion appconfiguration en la base de datos **appconfiguration** los roles que tenga disponibles

Estos roles se van a comparar con los del usuario que esta intentando loguearse para determinar si puede acceder con alguno de sus roles.

```json
{
  "_id" : ObjectId("61096e5dff8953411b37fb94"),
  "active" : true,
  "applicative" : {
    "idapplicative" : 6
  },
  "idappconfiguration" : NumberLong(1),
  "role" : [{
      "idrole" : NumberLong(1)
    }, {
      "idrole" : NumberLong(5)
    }, {
      "idrole" : NumberLong(7)
    }, {
      "idrole" : NumberLong(8)
    }, {
      "idrole" : NumberLong(16)
    }]
}

```
Si observa para la aplicacion 6 definimos los roles 1,5,7,8,16


## Validar los roles por modulo

Utilice appmoduleconfiguracion especificando la aplicacion el modulo y el evento y puede validar los roles permitidos


```json
{
  "_id" : ObjectId("63c819cf3e4b8e108cde65a1"),
  "active" : true,
  "applicative" : {
    "idapplicative" : NumberLong(6)
  },
  "event" : "crear proyecto",
  "idappmoduleconfiguration" : NumberLong(1),
  "module" : "jefe-unidad",
  "role" : [{
      "idrole" : NumberLong(1)
    }, {
      "idrole" : NumberLong(8)
    }]
}

```

Aqui recuerde que si necesita validar modulos y eventos espeficios los debe creear en la coleccion appmoduleconfig.

## Estilo de login
configure la propriedad **loginStyle** en el archivo microprofile-properties
```xml
loginStyle=simple
loginStyle=split
loginStyle=feature
loginStyle=carousel
loginStyle=glass

```
Las paginas de login tendran la siguiente sintaxis: 
```xml
 ${loginSytyle}.xhtml
```
