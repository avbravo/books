
# 23. Manejo de imagenes

## Configurar las rutas en el archivo microprofile-config.properties

```xml
#--------------------------------------------------------------
#--Path Images
#--  si pathBaseLinuxAddUserHome  (solo para Linux JsfUtil.isLinux())
#--  PhotoUser siempre debe contener el path a accreditation, ya que es la aplicación que gestiona todos los usuarios
#--  si es true se agrega JsfUtil.userHome()  al path (/asistencia/imagenes => /home/miuser/asistencia/imagenes)
#--  si es false = se usa el path completo de pathLinux (/opt/asistencia/imagenes)

pathBaseLinuxAddUserHome=true
pathLinux=/sft/images/
pathLinuxPhotoGeneral=/sft/images/general/
pathLinuxPhotoUser=/accreditation/images/user/

pathWindows=C:\\sft\\images\\
pathWindowsPhotoGeneral=C:\\sft\\images\\general\\
pathWindowsPhotoUser=C:\\accreditation\\images\\user\\

```

## Para descargar archivos use

```java
  @Inject
    JmoordbCoreMediaContext jmoordbCoreMediaContext;

```

En el init()

```java
 // <editor-fold defaultstate="collapsed" desc=" init">
    @PostConstruct
    public void init() {
        try {
            userLogged = (User)JmoordbCoreContext.get("LoginFaces.userLogged");
            //Cargar el media type
            saveToMediaContext(userLogged.getPhoto());
        } catch (Exception e) {
        }

    }
// </editor-fold>


```

Cree el metodo

```java
  // <editor-fold defaultstate="collapsed" desc="String saveToMediaContext(String pathOfFile)">
    public String saveToMediaContext(String pathOfFile) {
        try {
           
            jmoordbCoreMediaContext.put("pathOfFile", pathOfFile);
        } catch (Exception e) {
            
        }

        return "";
    }
    // </editor-fold>
}


```
