
## 61. Ajustar ancho de los <div>

```xml
<dashboard:top/>
                   
<div class="surface-section"  style="max-width: 970px;">

```

## Con  una clase

Agregue al archivo jmoordbcore.css

```
   .jmoordbcore-max-width970{
        max-width: 970px;
    }

```

En el formulario sprint.xhtml
agregue

```
 <dashboard:top/>
 <div class="surface-section , jmoordbcore-max-width970">

```
