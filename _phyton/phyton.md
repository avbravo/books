# Phyton

## Actualizar  

```shell

sudo apt update && sudo apt upgrade -y

```

Probar phyton

```shell

python --version

```
Aparece vacio.


Probar phyton3

```shell

python3 --version

```

Asignar Phyton3 como Phyton

```shell
sudo apt install python-is-python3
```

Ahora se puede usar phyton3 como phyton
```shell

python --version

```
