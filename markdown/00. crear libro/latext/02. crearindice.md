```html

- [<span class="indice">Presentación</span>](#00d_presentacion)

- [<span class="indice">Configuración</span>](#00i_configuracion)
- [Capitulo 1: <span class="indice">Entidades</span>](#01_entity_1_entidades)  
     [          <span class="indice">1.0 @Entity</span>](#01_entity_1_0_arrobaentity)  
     [          <span class="indice">1.1 @Id</span>](#01_entity_1_1_arrobaid)
```

2. En cada archivo que deseamos enlazar devemos crear unos div para identificarlos
por ejemplo archivo. 01_entity.md
denominamos las secciones con el nombre del archivo: 01_entity_<nombre-de-la-etiqueta>
en mi caso particular las etiqutas por ejemplo
@Id las definimo como 01_entity_arrobaid
uso el nombre del caracter para identificarlo y evitar cualquier conflicto
