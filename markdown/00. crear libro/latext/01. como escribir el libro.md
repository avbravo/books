Instalar Pandoc
Pasos:
1. Instalar pandoc
[Pagina de Descarga](https://pandoc.org/installing.html)

2. Instalar

sudo apt-get install texlive

2.1 bajar
git clone https://github.com/silkeh/latex-sourcesanspro


3. Crear una carpeta nueva
```shell
mkdir markdownbook
```

```shell
cd markdownbook
```
4. Crear el archivo book.md

```shell
gedit book.md
```

5. Escribir el texto
Referencia

6. Si usa imagenes colocarlas en el mismo directorio

7. Conversiones
 Word
```shell
pandoc book.md -o book.docx
```
OpenDocument
```shell
pandoc book.md -o book.odt
```
PDf
```shell
pandoc book.md -o book.pdf
```

EPUB
```shell
pandoc book.md -o book.epub
```
