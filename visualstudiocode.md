```
Phind - AI with Codebase Context
Use the input box at the bottom to ask questions. Phind will automatically use your codebase to answer.

Type @ to use specific files/code in your query.

@web_search to use the internet with your query.

Press Ctrl/Cmd + I to start a new chat with your current selection.

With code selected, press Ctrl/Cmd + Shift + I to add your current selection to the existing chat.

With code selected, press Ctrl/Cmd + Shift + M to automatically rewrite the selection based on your instructions.

Use Ctrl/Cmd + Shift + L to ask phind about the terminal output.

Use Ctrl/Cmd + Shift + J to simply open/close the phind panel.

To Enable Autocomplete, Cmd+Shift+P -> "Enable tab completion with Phind"



```
