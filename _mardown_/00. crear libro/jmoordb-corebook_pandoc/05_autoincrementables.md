##  Autoincrementables
   
 MongoDB no soporta campos autoincrementables, para utilizarlos el framework, 
lo resuelve mediante la utilización de una colección alternativa, para llevar 
el control de las secuencias de valores. Internamente se utiliza el método
findOneAndUpdate() de MongoDB que consulta un  valor de un atributo incrementandolo
en la misma operación.
 En este capítulo usaremos los términos autoincrementables y secuenciales para 
referirnos al proceso de crear un valor que se incrementa automáticamente,


## @AutosecuenceRepository  

  Para lograr esta implementación usted solo debe crear una interface de tipo 
@AutosecuenceRepository, ubicada en el mismo paquete donde están sus repositorios. 
El framework generará todo el código necesario para hacer la implementación. 
@AutoincrementRepository está asociado al empleo de @Id(autogeneratedActive = AutogeneratedActive.ON)
con atributos de tipo Long en las entidades.
Es recomendable generar un índice para cada colección para incrementar la 
velocidad de las operaciones con la base  de datos.
Por defecto se usa la base de datos principal definida en el archivo de
configuración microprofile-config.properties,{mongodb.database}. Usted puede 
especificar otra base de datos configurándola en ese archivo,  de manera que al
crear la interface mediante la anotación @AutoincrementRepository establezca el nombre 
de la propiedad que identifica a la base de datos en el atributo database().

### AutosecuenceRepository  

Estructura de la anotación:

\small
```java
@Target(ElementType.TYPE)
@Retention(RetentionPolicy.SOURCE)
public @interface AutosecuenceRepository {
    Class<?> entity();
    JakartaSource jakartaSource() default JakartaSource.JAKARTA;
    String collection() default "autosequence";
    /**
     * database_name --> Es un nombre de base de datos que indique el
     * desarrollador {mongodb.database} --> Es el parametro en
     * Microorofile-config.properties
     *
     * @return
     */
    String database() default "{mongodb.database}";

}

```
\normalsize
 

###  @Autogenerated
Esta anotación indica que el método deberá tener la estructura Long generate
(String database, String collection).

Estructura de la anotación:

\small
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.SOURCE)
public @interface Autogenerated { }
```
\normalsize
 

###  Autosequence.
Esta clase representa una entidad asociada a una  colección en la base de datos
que sera usada para controlar los valores autoincrementables. No necesita 
definirla ya que forma parte del framework.

\small
```java
@Entity
public class Autosequence {
    @Id
    private String databasecollection;
    private Long secuence;

    public Autosequence() {
    }
}
```
\normalsize

El framework creara en la base de datos MongoSB una colección denominada **autosequence**
con un esquema similar al siguiente


\small
```json
autosequence{
         databasecollection:"world_profesion",
         sequence: 1

}

```
\normalsize

Se crea un documento para cada colección almacenando el nombre en el atributo 
databasecollection con la siguiente sintaxis: **nombrebasedatos_nombrecoleccion**,
y el atributo sequence, es un contador en el cual en cada ocasión que se consulte
incrementara su valor en 1, de esta manera podemos administrar el incremento directamente.


### AutogeneratedRepository

Usted  debe crear la interface AutogenerationRepository en el paquete donde 
estan los demás repositorio. El framework utiliza de manera reservada este repositorio
para gestionar los valores autoincrementables de las entidades.
Debe contener una declaración  similar a la siguiente

\small
```java
@AutosecuenceRepository(entity = Autosequence.class, 
        jakartaSource = JakartaSource.JAKARTA,
        database = "{mongodb.database}", collection = "autoincrementable")  
```
\normalsize

Incluya la definición del método generate(), como se muestra a continuación:

\small
```java
   public Long generate(String database,String collection);
```
\normalsize


|Atributo                      | Descripción | 
|-----------                          | -----------    |
|                                     |                |  
|AutogeneratedRepository              |Es inalterable  |  
|entity = Autosequence.class          |Es inalterable  |  
|jakartaSource =JakartaSource.JAKARTA |Especifique si usara Jakarta o Java EE.|  
|database=""                          |Base de datos especificada en el archivo microprofile-config.properties|  
|collection ="sequence"               |Es inalterable  |  

De forma predeterminada se generará la implementación de la interface y se 
inyectara en los repositorios que utilicen autoincrementables.

Código completo de la interface AutogeneratedRepository, que debe crear en su
proyecto se describe a continuación:

\small
```java
import com.jmoordb.core.annotation.enumerations.JakartaSource;
import com.jmoordb.core.model.Autosequence;
import com.jmoordb.core.annotation.autosecuence.Autogenerated;
import com.jmoordb.core.annotation.autosecuence.AutosecuenceRepository;


/**
 *
 * @author avbravo
 */
@AutosecuenceRepository(entity = Autosequence.class, 
                    jakartaSource = JakartaSource.JAKARTA,
                    database = "{mongodb.database}", collection = "autosecuence")
public interface AutogeneratedRepository {

  @Autogenerated() 
  public Long generate(String database,String collection);

}
```
\normalsize
 

Es lo único que usted necesita para trabajar con llaves primarias secuenciales o
autoincrementables, el framework internamente se encarga del uso en cada repositorio
en el que se ha identificado que la entidad tiene definida una llave primaria @Id,
que utiliza valores autoincrementables.



## ¿Cómo se realiza el proceso internamente?
 Muchas veces no conocemos cómo los frameworks y APIs realizan una serie de operaciones
internas para brindarnos muchas de las funcionalidades que necesitamos en los 
proyectos, Para aclarar un poco el proceso interno que se realiza en tiempo de 
compilación, se mostrará un ejemplo simple de una entidad llamada **Persona** que 
posee una llave primaria de tipo autoincrementable.

\small
```java
@Entity
public class Persona {
        @Id(autogeneratedActive = AutogeneratedActive.ON)
    private Long idpersona;

    @Column
    private String nombre;

    public Persona() {
    }

    public Long getIdpersona() {
        return idpersona;
    }

    public void setIdpersona(Long idpersona) {
        this.idpersona = idpersona;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }   
}


```
\normalsize

Defina el repositorio para la entidad

\small
```java
@Repository(entity = Persona.class)
public interface PersonaRepository extends CrudRepository<Persona, Long> {
    
}

```
\normalsize

Cuando ocurre la compilación del proyecto, el framework genera el código necesario
en la clase **PersonaRepositoryImpl** para manejar las operaciones C.R.U.D. 
establecidas en CrudRepository.

\small
```java
@ApplicationScoped
public class PersonaRepositoryImpl  implements PersonaRepository{
   @Inject
   MongoClient mongoClient;
   @Inject
   private Config config;
   @Inject
   @ConfigProperty(name = "mongodb.database")
   private String mongodbDatabase;
   private String mongodbCollection = "persona";
   @Inject
   AutogeneratedRepository autogeneratedRepository;
   @Inject
   PersonaSupplier personaSupplier;


@Override
public Optional<Persona> save(Persona persona) {
try {
MongoDatabase database = mongoClient.getDatabase(mongodbDatabase);
mongoCollection<Document> collection = database.getCollection(mongodbCollection);
if (findByPk(persona.getIdpersona()).isPresent()) { 
    MessagesUtil.warning("There is already a record with that id");
   return Optional.of(persona);
}
persona.setIdpersona(autogeneratedRepository.generate(mongodbDatabase,
                     mongodbCollection));
Jsonb jsonb = JsonbBuilder.create();
InsertOneResult insertOneResult = collection.insertOne(Document.parse(
                                                       jsonb.toJson(persona)));
if (insertOneResult.getInsertedId() != null) {
   return Optional.of(persona);
}
} catch (Exception e) {
 MessagesUtil.error(MessagesUtil.nameOfClassAndMethod() + " " + 
                   e.getLocalizedMessage());
 }
 return Optional.empty();
 }

// El código de los demás métodos se omite en el ejemplo

}
```
\normalsize

Puede observar que se inyecta el repositorio **AutogeneratedRepository** y 
en el método save()  , se realiza el incremento del atributo idpersona al invocar
el método autogeneratedRepository.generate().

\small
```java
persona.setIdpersona(autogeneratedRepository.generate(mongodbDatabase,
                                                      mongodbCollection));
```
