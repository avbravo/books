# Salto de pagina
- para hacer saltos de pagina cuando generamos con pandoc 
- No tiene efecto en un visor de markdown directo
utilice 
```
\newpage
pagina 1
\newpage
pagina 2
\newpage
```
En un visor de markdown se ve de esta mamera, pero en pandoc genera correctamente el salto de pagina.

\newpage
pagina 1
\newpage
pagina 2
\newpage
