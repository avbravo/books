## Referencias
### PROYECTOS

Los siguientes son proyectos creados que se utilizaron para la creación del
framework. Muchos de ellos marcaron la estructura y prueba de conceptos 
aplicados a jmoordb-core.
Iniciamos con ellos con fines académicos.

#### jmoordb-core:
- Proyecto que genera codigo en tiempo de compilación  
[jmoordb-core-processor](https://github.com/avbravo/jmoordb-core-processor.git)  
- Proyecto que se usa de ejemplo de generación de codigo con jmoordb-core  
[jmoordb-core-processor-example](https://github.com/avbravo/jmoordb-core-processor-example.git)

- Proyecto que usa Java Nativo con MongoDB base para jmoordb-core-processor  
[jmoordb-core-processor-javadriver](https://github.com/avbravo/jmoordb-core-processor-javadriver.git) 

- Proyecto JavaSE que muestra como separar los nombres de método y validar parámetros
[jmoordbnameseparator](https://github.com/avbravo/jmoordbnameseparator.git)

#### jmoordbgenesis 
- API para manejar mongodb con java
[jmoordbgenesis](https://github.com/avbravo/jmoordbgenesis)  

- Proyecto Web que crea repositorios y tiene ejemplos  
[microgenesis](https://github.com/avbravo/microgenesis)  



#### Proyecto MongoDB que usa lookup directo
Muestra como generar y procesar los lookup
Características:
- Cada Lookup genera un Array que debe ser procesado
- LookupSupplier genera los lookup
- EntitySupplier procesa los cursor de resultado
- El problema es el performance de los lookups
[mongodbjavalookup](https://github.com/avbravo/mongodbjavalookup.git)

#### Proyecto con Java Driver que usa invocaciones en cada etapa
- Muestra como usar java driver directamente
- Implementa búsquedas en los Referenciados
- Se usa para obtener el codigo que sera usado desde el proccess en tiempo de compilación.  
[mongodbjavadirect](https://github.com/avbravo/mongodbjavadirect.git)
