
27. Rendered Multiples llamados

cuando necesitamos invocar a los rendered para mostrar o no elementos y estos deben ser a un mimos metodo complejo
podemos usar un atributo alterno para el segundo llamado en adelante.

```java
    private Boolean haveOpenSprintTemporal= Boolean.FALSE;
```


```java
// <editor-fold defaultstate="collapsed" desc="Boolean haveOpenSprint(Proyecto proyecto)">
    
   public Boolean haveOpenSprint(Proyecto proyecto){
       Boolean result = Boolean.FALSE;
       try {
           
            result = sprintServices.havaOpenSpint(proyecto);
            haveOpenSprintTemporal = result;
           
       } catch (Exception e) {
            FacesUtil.errorMessage(FacesUtil.nameOfMethod() + " " + e.getLocalizedMessage());
        }
       return result;
   }
// </editor-fold>

```

En la pagina xhtml


```xhtml

 <div class="px-4 py-3 surface-100 text-right">
<p:commandButton id="commandButtonResumen" 
                 rendered="#{dashboardFaces.showEstadistica()}"
                 icon="pi pi-eye"  title="#{msg['button.resumen']}" styleClass="rounded-button ui-button-info"/>




<p:commandButton  icon="pi pi-table" value="#{core['button.board']}" styleClass="rounded-button ui-button-success"
                  rendered="#{dashboardFaces.haveOpenSprint(proyecto)}"
                  action="#{dashboardFaces.goTablero(proyecto)}"/>

<p:commandButton id="commandButtonSprint" 
                 rendered="#{!dashboardFaces.haveOpenSprintTemporal}"
                 icon="pi-calendar-plus"  title="#{msg['button.sprint']}" styleClass="rounded-button ui-button-warning"/>




</div>

```
Observe que el primero llama al metodo que realiza las operaciones
```java

 <p:commandButton  icon="pi pi-table" value="#{core['button.board']}" styleClass="rounded-button ui-button-success"
                                                  rendered="#{dashboardFaces.haveOpenSprint(proyecto)}"
                                                  action="#{dashboardFaces.goTablero(proyecto)}"/>


```

y el segundo usa el atributo **haveOpenSprintTemporal** y no el metodo.

```java
<p:commandButton id="commandButtonSprint" 
     rendered="#{!dashboardFaces.haveOpenSprintTemporal}"
     icon="pi-calendar-plus"  title="#{msg['button.sprint']}" styleClass="rounded-button ui-button-warning"/>

```
