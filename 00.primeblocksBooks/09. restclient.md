
# 08 RestClient (Basic) Authentication

Para conectarnos al microservicio usaremos Microprofile RestClient con (Basic) Authentication

Algunos conceptos basicos
- Cree una interface similar a los endpoints que desea conectarse
- Si necesita autentificación debe agregar la anotación @ClientHeaderParam(name = "Authorization", value = "{lookupAuth}") y crear el metodo lookupAuth(), y configurar en el propertie las credenciales
- Debe registrar en el archivo microprofile la interface cliente con el url al microservicio
- Debe indicar en el archivo microprofile-config las credenciales de autentificación encriptadas

## RESTClient con lookup(Search search)


### Ejemplo

Nos adelantaremos un poco para mostrar como usar lookup en un Microservicios y en un cliente.

Puede observar que usamos el método DocumentUtil.convertForLookup que se encarga de convertir las parámetros a un Search.

```java

  @GET
  @Path("lookup")
  @Produces({MediaType.APPLICATION_XML, MediaType.APPLICATION_JSON})
  public List<Appconfiguration> lookup(@QueryParam("filter") String filter, @QueryParam("sort") String sort,
            @QueryParam("page") Integer page, @QueryParam("size") Integer size) {
        List<Appconfiguration> suggestions = new ArrayList<>();
        try {
        Search search = DocumentUtil.convertForLookup(filter, sort, page, size);
        suggestions = appconfigurationRepository.lookup(search);
        } catch (Exception e) {
     
          MessagesUtil.error(MessagesUtil.nameOfClassAndMethod() + "error: " + e.getLocalizedMessage());
        }  
        return suggestions;
    }

```
