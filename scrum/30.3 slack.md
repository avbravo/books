# 30.2 Slack


## Integrar Slack con Trello

###  Ejemplo
- Ayuda
 ```
 /trello help
 ```

 - Crear una tarjeta
 ```
 /trello add Formulario-Login
 ```
 - Asignarle colaborador
 ```
 /trello assign @aristides
 ```
 - Agregar comentario
 ```
 /trello comment Formulario de validación de acceso
 ```
 - Indicar la fecha de vencimiento.
 ```
 /trello set-due next Friday at 5pm
 ```

 - Cambiar a una columna del tablero (El numero corresponde al indice de la lista) (Perdiente, en progreso ,test, finalizado). Depeniendo de las que usted creo.
/trello set-list 1 


- Busqueda
 ```
/trello search Formulario-Login
 ``` 

 - Mostrar detalles de una tarjeta
 Abra la tarjeta en Trello y puede ver el url en el navegador
 
  ```
/trello [board or card url]

/trello https://trello.com/c/Fm8QUiAn/10-formulario-login
 ```
