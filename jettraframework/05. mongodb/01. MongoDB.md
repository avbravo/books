Creating a custom dependency injection framework for Java SE with support for MongoDB and the repository pattern, while avoiding Jakarta EE, can be a challenging but rewarding task. Below is an implementation that demonstrates how to achieve this using Java's `@Inject` and `@Produces` annotations (custom implementations), along with a simple HTTP handler.

---

### **Step 1: Define Custom Annotations**
We need custom annotations to mimic `@Inject` and `@Produces`.

```java
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;

@Retention(RetentionPolicy.RUNTIME)
public @interface Inject {}

@Retention(RetentionPolicy.RUNTIME)
public @interface Produces {}
```

---

### **Step 2: Create a Dependency Injection Framework**
This framework will scan for dependencies and inject them where needed.

```java
import java.lang.reflect.Field;
import java.util.HashMap;
import java.util.Map;

public class DependencyInjector {
    private final Map<Class<?>, Object> context = new HashMap<>();

    public <T> void register(Class<T> type, T instance) {
        context.put(type, instance);
    }

    public <T> T resolve(Class<T> type) {
        return type.cast(context.get(type));
    }

    public void injectDependencies(Object target) throws IllegalAccessException {
        for (Field field : target.getClass().getDeclaredFields()) {
            if (field.isAnnotationPresent(Inject.class)) {
                field.setAccessible(true);
                Class<?> fieldType = field.getType();
                Object dependency = resolve(fieldType);
                if (dependency == null) {
                    throw new RuntimeException("No dependency found for type: " + fieldType.getName());
                }
                field.set(target, dependency);
            }
        }
    }
}
```

### **Step 3: Define the Person Entity**
This is the entity we will persist in MongoDB.

public class Person {
    private String id;

### **Step 4: Implement the Repository Pattern**
The repository will handle MongoDB operations.

```java
import com.mongodb.client.MongoClient;
import com.mongodb.client.MongoCollection;
import com.mongodb.client.MongoDatabase;
import org.bson.Document;

import javax.inject.Inject;
import java.util.ArrayList;
import java.util.List;

public class PersonRepository {
    private final MongoCollection<Document> collection;

    @Inject
    public PersonRepository(MongoClient mongoClient) {
        MongoDatabase database = mongoClient.getDatabase("testdb");
        this.collection = database.getCollection("people");
    }

    public void save(Person person) {
        Document doc = new Document("name", person.getName())
                .append("age", person.getAge());
        collection.insertOne(doc);
    }

    public List<Person> findAll() {
        List<Person> people = new ArrayList<>();
        for (Document doc : collection.find()) {
            Person person = new Person();
            person.setId(doc.getObjectId("_id").toString());
            person.setName(doc.getString("name"));
            person.setAge(doc.getInteger("age"));
            people.add(person);
        }
        return people;
    }
}
```

### **Step 5: Create a Producer for MongoClient**
This will provide the MongoDB client instance.

```java
import com.mongodb.MongoClient;

public class MongoProducer {
    @Produces
    public MongoClient createMongoClient() {
        return new MongoClient("localhost", 27017);
    }
}
```

---

### **Step 6: Implement an HTTP Handler**
This will expose endpoints to interact with the `PersonRepository`.

```java
import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpServer;

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.nio.charset.StandardCharsets;
import java.util.List;

public class PersonHttpHandler implements HttpHandler {
    private final PersonRepository personRepository;

    @Inject
    public PersonHttpHandler(PersonRepository personRepository) {
        this.personRepository = personRepository;
    }

    @Override
    public void handle(HttpExchange exchange) throws IOException {
        if ("GET".equals(exchange.getRequestMethod())) {
            List<Person> people = personRepository.findAll();
            String response = people.toString();
            exchange.sendResponseHeaders(200, response.getBytes(StandardCharsets.UTF_8).length);
            OutputStream os = exchange.getResponseBody();
            os.write(response.getBytes(StandardCharsets.UTF_8));
            os.close();
        } else {
            exchange.sendResponseHeaders(405, -1); // Method Not Allowed
        }
    }

    public static void main(String[] args) throws Exception {
        DependencyInjector injector = new DependencyInjector();

        // Register dependencies
        MongoProducer producer = new MongoProducer();
        injector.register(MongoClient.class, producer.createMongoClient());
        injector.register(PersonRepository.class, new PersonRepository(injector.resolve(MongoClient.class)));

        // Create and inject HTTP handler
        PersonHttpHandler handler = new PersonHttpHandler(null);
        injector.injectDependencies(handler);

        // Start HTTP server
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/people", handler);
        server.setExecutor(null); // Use the default executor
        server.start();
        System.out.println("Server started on port 8080");
    }
}
```

---

### **Explanation of the Code**
1. **Custom Dependency Injection**: The `DependencyInjector` class manages the lifecycle of objects and injects dependencies into fields annotated with `@Inject`.
2. **Repository Pattern**: The `PersonRepository` abstracts MongoDB operations for the `Person` entity.
3. **Producer for MongoClient**: The `MongoProducer` provides a `MongoClient` instance, which is registered in the dependency injector.
4. **HTTP Handler**: The `PersonHttpHandler` exposes a REST-like endpoint to fetch all `Person` records from MongoDB.

---

### **How to Run**
1. Ensure MongoDB is running locally on `localhost:27017`.
2. Compile and run the `PersonHttpHandler` class.
3. Access `http://localhost:8080/people` in your browser or via a tool like `curl` to see the list of people.

This implementation avoids Jakarta EE and demonstrates a lightweight approach to dependency injection and repository pattern integration in Java SE.
