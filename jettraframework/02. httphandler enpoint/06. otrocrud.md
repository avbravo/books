Vamos a generar un **CRUD completo** para la clase `Persona` utilizando **Java Annotation Processing**. Este enfoque generará automáticamente los handlers necesarios para manejar las operaciones CRUD (Create, Read, Update, Delete) basadas en una anotación personalizada.

### 1. Estructura del proyecto

El proyecto tendrá las siguientes partes:

1. **Clase `Persona`**: Representa el recurso con atributos como `id`, `nombre`, y `edad`.
2. **Anotación personalizada (`@CRUD`)**: Para marcar las clases que deben tener endpoints CRUD.
3. **Procesador de anotaciones**: Genera el código necesario para registrar los endpoints CRUD.
4. **Clase principal del servidor**: Inicia el servidor HTTP y utiliza los endpoints generados.

---

### 2. Implementación paso a paso

#### **Paso 2: Anotación personalizada (`@CRUD`)**

Creamos una anotación personalizada llamada `@CRUD`. Esta anotación se usará para marcar las clases que representan recursos con operaciones CRUD.

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

@Retention(RetentionPolicy.SOURCE)
@Target(ElementType.TYPE)
public @interface CRUD {
    String path();
}
```

- `path()`: Define la ruta base del recurso (por ejemplo, `/personas`).
- `@Retention(RetentionPolicy.SOURCE)`: Indica que la anotación solo estará disponible durante la fase de compilación.

---

#### **Paso 3: Procesador de anotaciones**

El procesador de anotaciones buscará todas las clases anotadas con `@CRUD` y generará el código necesario para registrar los endpoints CRUD en el servidor HTTP.

```java
import javax.annotation.processing.AbstractProcessor;
import javax.annotation.processing.RoundEnvironment;
import javax.annotation.processing.SupportedAnnotationTypes;
import javax.annotation.processing.SupportedSourceVersion;
import javax.lang.model.SourceVersion;
import javax.lang.model.element.Element;
import javax.lang.model.element.TypeElement;
import javax.tools.JavaFileObject;
import java.io.IOException;
import java.io.PrintWriter;
import java.util.Set;

@SupportedAnnotationTypes("CRUD")
@SupportedSourceVersion(SourceVersion.RELEASE_8)
public class CRUDProcessor extends AbstractProcessor {

    @Override
    public boolean process(Set<? extends TypeElement> annotations, RoundEnvironment roundEnv) {
        // Iterar sobre todos los elementos anotados con @CRUD
        for (Element element : roundEnv.getElementsAnnotatedWith(CRUD.class)) {
            if (element instanceof TypeElement) {
                TypeElement typeElement = (TypeElement) element;
                CRUD crudAnnotation = typeElement.getAnnotation(CRUD.class);
                String basePath = crudAnnotation.path();
                String className = typeElement.getSimpleName().toString();

                // Generar el código para los endpoints CRUD
                try {
                    generateCRUDHandlerCode(className, basePath);
                } catch (IOException e) {
                    e.printStackTrace();
                }
            }
        }
        return true;
    }

    private void generateCRUDHandlerCode(String className, String basePath) throws IOException {
        // Nombre del archivo generado
        String handlerClassName = className + "CRUDHandler";
        JavaFileObject builderFile = processingEnv.getFiler().createSourceFile(handlerClassName);

        // Escribir el código del handler
        try (PrintWriter out = new PrintWriter(builderFile.openWriter())) {
            out.println("import com.sun.net.httpserver.HttpHandler;");
            out.println("import com.sun.net.httpserver.HttpExchange;");
            out.println("import java.io.IOException;");
            out.println("import java.io.OutputStream;");
            out.println("import java.io.InputStream;");
            out.println("import java.util.ArrayList;");
            out.println("import java.util.List;");
            out.println("import java.util.Optional;");
            out.println();
            out.println("public class " + handlerClassName + " implements HttpHandler {");
            out.println("    private static List<" + className + "> items = new ArrayList<>();");
            out.println("    private static int idCounter = 1;");
            out.println();
            out.println("    @Override");
            out.println("    public void handle(HttpExchange exchange) throws IOException {");
            out.println("        String method = exchange.getRequestMethod();");
            out.println("        String path = exchange.getRequestURI().getPath();");
            out.println();
            out.println("        // GET /basePath: Obtener todos los elementos");
            out.println("        if (\"GET\".equals(method) && path.equals(\"" + basePath + "\")) {");
            out.println("            String response = items.toString();");
            out.println("            exchange.sendResponseHeaders(200, response.getBytes().length);");
            out.println("            OutputStream os = exchange.getResponseBody();");
            out.println("            os.write(response.getBytes());");
            out.println("            os.close();");
            out.println("        }");
            out.println("        // GET /basePath/{id}: Obtener un elemento por ID");
            out.println("        else if (\"GET\".equals(method) && path.startsWith(\"" + basePath + "/\")) {");
            out.println("            int id = Integer.parseInt(path.substring(path.lastIndexOf(\"/\") + 1));");
            out.println("            Optional<" + className + "> itemOpt = items.stream()");
            out.println("                .filter(i -> i.getId() == id)");
            out.println("                .findFirst();");
            out.println("            if (itemOpt.isPresent()) {");
            out.println("                String response = itemOpt.get().toString();");
            out.println("                exchange.sendResponseHeaders(200, response.getBytes().length);");
            out.println("                OutputStream os = exchange.getResponseBody();");
            out.println("                os.write(response.getBytes());");
            out.println("                os.close();");
            out.println("            } else {");
            out.println("                exchange.sendResponseHeaders(404, -1);");
            out.println("            }");
            out.println("        }");
            out.println("        // POST /basePath: Crear un nuevo elemento");
            out.println("        else if (\"POST\".equals(method) && path.equals(\"" + basePath + "\")) {");
            out.println("            InputStream requestBody = exchange.getRequestBody();");
            out.println("            String body = new String(requestBody.readAllBytes());");
            out.println("            String[] parts = body.split(\",\");");
            out.println("            " + className + " newItem = new " + className + "(idCounter++, parts[0], Integer.parseInt(parts[1]));");
            out.println("            items.add(newItem);");
            out.println("            String response = \"Creado: \" + newItem;");
            out.println("            exchange.sendResponseHeaders(201, response.getBytes().length);");
            out.println("            OutputStream os = exchange.getResponseBody();");
            out.println("            os.write(response.getBytes());");
            out.println("            os.close();");
            out.println("        }");
            out.println("        // PUT /basePath/{id}: Actualizar un elemento");
            out.println("        else if (\"PUT\".equals(method) && path.startsWith(\"" + basePath + "/\")) {");
            out.println("            int id = Integer.parseInt(path.substring(path.lastIndexOf(\"/\") + 1));");
            out.println("            Optional<" + className + "> itemOpt = items.stream()");
            out.println("                .filter(i -> i.getId() == id)");
            out.println("                .findFirst();");
            out.println("            if (itemOpt.isPresent()) {");
            out.println("                InputStream requestBody = exchange.getRequestBody();");
            out.println("                String body = new String(requestBody.readAllBytes());");
            out.println("                String[] parts = body.split(\",\");");
            out.println("                " + className + " item = itemOpt.get();");
            out.println("                item.setNombre(parts[0]);");
            out.println("                item.setEdad(Integer.parseInt(parts[1]));");
            out.println("                String response = \"Actualizado: \" + item;");
            out.println("                exchange.sendResponseHeaders(200, response.getBytes().length);");
            out.println("                OutputStream os = exchange.getResponseBody();");
            out.println("                os.write(response.getBytes());");
            out.println("                os.close();");
            out.println("            } else {");
            out.println("                exchange.sendResponseHeaders(404, -1);");
            out.println("            }");
            out.println("        }");
            out.println("        // DELETE /basePath/{id}: Eliminar un elemento");
            out.println("        else if (\"DELETE\".equals(method) && path.startsWith(\"" + basePath + "/\")) {");
            out.println("            int id = Integer.parseInt(path.substring(path.lastIndexOf(\"/\") + 1));");
            out.println("            Optional<" + className + "> itemOpt = items.stream()");
            out.println("                .filter(i -> i.getId() == id)");
            out.println("                .findFirst();");
            out.println("            if (itemOpt.isPresent()) {");
            out.println("                items.remove(itemOpt.get());");
            out.println("                exchange.sendResponseHeaders(204, -1);");
            out.println("            } else {");
            out.println("                exchange.sendResponseHeaders(404, -1);");
            out.println("            }");
            out.println("        }");
            out.println("        else {");
            out.println("            exchange.sendResponseHeaders(405, -1);");
            out.println("        }");
            out.println("    }");
            out.println("}");
        }
    }
}
```

Este procesador genera una clase `Handler` para cada clase anotada con `@CRUD`. La clase generada implementa `HttpHandler` y maneja las operaciones CRUD.

#### **Paso 4: Clase principal del servidor**

Ahora, creamos la clase principal del servidor que registrará los endpoints generados.

```java
import com.sun.net.httpserver.HttpServer;

import java.io.IOException;
import java.net.InetSocketAddress;

public class MainServer {

    public static void main(String[] args) throws IOException {
        // Crear una instancia del servidor HTTP
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);

        // Registrar los endpoints generados
        server.createContext("/personas", new PersonaCRUDHandler());

        // Iniciar el servidor
        server.setExecutor(null); // Usa el executor por defecto
        server.start();
        System.out.println("Servidor iniciado en http://localhost:8080");
    }
}
```

#### **Paso 6: Compilación y ejecución**

Para compilar y ejecutar el proyecto, sigue estos pasos:

1. Asegúrate de que el procesador de anotaciones esté correctamente configurado en tu proyecto.
2. Compila el proyecto:
   ```bash
   javac -processor CRUDProcessor MainServer.java Persona.java
   ```
3. Ejecuta el servidor:
   ```bash
   java MainServer
   ```

### 8. Conclusión

Este ejemplo muestra cómo usar **Java Annotation Processing** para generar automáticamente los métodos CRUD para la clase `Persona`. El procesador de anotaciones genera el código necesario para manejar las operaciones CRUD, lo que reduce la cantidad de código repetitivo y mejora la modularidad del proyecto.

Este enfoque es ideal para proyectos donde deseas mantener el código limpio y modular, especialmente cuando tienes muchos recursos que requieren operaciones CRUD similares. Sin embargo, para aplicaciones más grandes y complejas, considera usar frameworks como Spring Boot, que ofrecen funcionalidades similares de manera más robusta.
