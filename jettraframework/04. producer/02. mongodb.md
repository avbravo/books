
Para mejorar el programa y hacer que el `Producer` devuelva una conexión a una base de datos MongoDB, podemos integrar la biblioteca oficial de MongoDB para Java (`mongodb-driver-sync`) en nuestro sistema de inyección de dependencias personalizado. A continuación, te muestro cómo modificar el programa para que el `DependencyInjector` maneje la creación y gestión de una conexión a MongoDB.

---

### **Pasos para implementar la conexión a MongoDB**

1. **Agregar la dependencia de MongoDB**:
   Si usas Maven, agrega la siguiente dependencia en tu archivo `pom.xml`:

   ```xml
   <dependency>
       <groupId>org.mongodb</groupId>
       <artifactId>mongodb-driver-sync</artifactId>
       <version>4.10.2</version> <!-- Usa la versión más reciente -->
   </dependency>
   ```

   Si no usas Maven, descarga el `.jar` del controlador MongoDB desde [Maven Central](https://search.maven.org/artifact/org.mongodb/mongodb-driver-sync) y añádelo manualmente a tu proyecto.

2. **Definir la interfaz y la implementación de la conexión**:
   Crearemos una interfaz común para representar la conexión a MongoDB y una implementación concreta que use el controlador oficial.

3. **Registrar el productor de la conexión**:
   Usaremos el `DependencyInjector` para registrar un productor que cree y configure la conexión a MongoDB.

4. **Inyectar la conexión en un cliente**:
   Finalmente, inyectaremos la conexión en una clase que la utilice para interactuar con la base de datos.

---

### **Código completo**

```java
import com.mongodb.client.MongoClient;
import com.mongodb.client.MongoClients;
import com.mongodb.client.MongoDatabase;

import java.util.HashMap;
import java.util.Map;
import java.util.function.Supplier;

// Interfaz común para la conexión a MongoDB
interface MongoConnection {
    MongoDatabase getDatabase(String databaseName);
}

// Implementación concreta de la conexión
class MongoConnectionImpl implements MongoConnection {

    private final MongoClient mongoClient;

    public MongoConnectionImpl(String connectionString) {
        // Crear el cliente MongoDB usando la cadena de conexión
        this.mongoClient = MongoClients.create(connectionString);
    }

    @Override
    public MongoDatabase getDatabase(String databaseName) {
        return mongoClient.getDatabase(databaseName);
    }
}

// Clase cliente que usa la conexión a MongoDB
class MongoDatabaseClient {

    private final MongoConnection mongoConnection;

    // Constructor para inyectar la dependencia
    public MongoDatabaseClient(MongoConnection mongoConnection) {
        this.mongoConnection = mongoConnection;
    }

    public void listarColecciones(String databaseName) {
        MongoDatabase database = mongoConnection.getDatabase(databaseName);
        System.out.println("Colecciones en la base de datos '" + databaseName + "':");
        for (String collectionName : database.listCollectionNames()) {
            System.out.println("- " + collectionName);
        }
    }
}

// Sistema de inyección de dependencias personalizado
class DependencyInjector {

    private final Map<Class<?>, Supplier<?>> producers = new HashMap<>();

    // Método para registrar un productor
    public <T> void registerProducer(Class<T> type, Supplier<T> producer) {
        producers.put(type, producer);
    }

    // Método para obtener una instancia de un tipo registrado
    @SuppressWarnings("unchecked")
    public <T> T getInstance(Class<T> type) {
        Supplier<?> producer = producers.get(type);
        if (producer == null) {
            throw new IllegalArgumentException("No producer registered for type: " + type.getName());
        }
        return (T) producer.get();
    }
}

// Clase principal para probar el sistema
public class Main {

    public static void main(String[] args) {
        // Crear el inyector de dependencias
        DependencyInjector injector = new DependencyInjector();

        // Registrar un productor para MongoConnection
        String connectionString = "mongodb://localhost:27017"; // Cambia esto según tu configuración
        injector.registerProducer(MongoConnection.class, () -> new MongoConnectionImpl(connectionString));

        // Obtener una instancia de MongoConnection
        MongoConnection mongoConnection = injector.getInstance(MongoConnection.class);

        // Crear el cliente y pasarle la dependencia
        MongoDatabaseClient client = new MongoDatabaseClient(mongoConnection);

        // Listar colecciones en una base de datos específica
        client.listarColecciones("test"); // Cambia "test" por el nombre de tu base de datos
    }
}
```

---

### **Explicación del código**

1. **Interfaz y clase de conexión (`MongoConnection`, `MongoConnectionImpl`)**:
   - La interfaz `MongoConnection` define un método para obtener una base de datos.
   - La clase `MongoConnectionImpl` implementa esta interfaz y utiliza el controlador MongoDB para crear una conexión.

2. **Clase cliente (`MongoDatabaseClient`)**:
   - Esta clase depende de `MongoConnection`. Recibe la dependencia a través de su constructor.
   - Proporciona un método para listar las colecciones en una base de datos específica.

3. **Sistema de inyección de dependencias (`DependencyInjector`)**:
   - Registramos un productor para `MongoConnection` que crea una instancia de `MongoConnectionImpl` con la cadena de conexión proporcionada.

4. **Lógica principal (`Main`)**:
   - Creamos una instancia de `DependencyInjector`.
   - Registramos un productor para `MongoConnection`.
   - Obtenemos una instancia de `MongoConnection` y la inyectamos en `MongoDatabaseClient`.
   - Llamamos al método `listarColecciones` para mostrar las colecciones en una base de datos.

---

### **Salida esperada**
Si tienes una base de datos llamada `test` en tu servidor MongoDB local, verás algo como esto:

```
Colecciones en la base de datos 'test':
- usuarios
- productos
```

Si no hay colecciones en la base de datos, la salida será:

```
Colecciones en la base de datos 'test':
```

### **Mejoras adicionales**

1. **Manejo de errores**:
   - Agrega manejo de excepciones para errores de conexión o consultas inválidas.

2. **Configuración externa**:
   - Usa un archivo de configuración (por ejemplo, `application.properties`) para almacenar la cadena de conexión y otros parámetros.

3. **Cierre de la conexión**:
   - Asegúrate de cerrar la conexión al finalizar el programa. Puedes agregar un método `close()` en `MongoConnectionImpl`.

4. **Soporte para operaciones CRUD**:
   - Extiende `MongoDatabaseClient` para incluir métodos para insertar, actualizar y eliminar documentos.
