## Cómo crear un sistema de almacenamiento de archivos distribuido usando golang


Crear un sistema de almacenamiento de archivos distribuido (Distributed File System, DFS) es una tarea compleja que requiere considerar varios aspectos, como la replicación, tolerancia a fallos, consistencia, rendimiento y escalabilidad. A continuación, te proporcionaré una guía paso a paso para implementar un sistema básico de almacenamiento de archivos distribuido utilizando Go (Golang).

---

### **1. Definición del Problema**
Un sistema de almacenamiento de archivos distribuido debe permitir:
- Almacenar archivos en múltiples nodos.
- Recuperar archivos desde cualquier nodo.
- Replicar archivos para garantizar tolerancia a fallos.
- Escalar horizontalmente al agregar más nodos.

---

### **2. Arquitectura Básica**
El sistema puede tener los siguientes componentes:
1. **Nodos de almacenamiento**: Servidores que almacenan fragmentos de archivos.
2. **Nodo maestro (Master Node)**: Un servidor central que gestiona metadatos (ubicación de archivos, estado de los nodos, etc.).
3. **Cliente**: Una aplicación que interactúa con el sistema para subir y descargar archivos.

---

### **3. Implementación Paso a Paso**

#### **3.1. Estructura del Proyecto**
Organiza tu proyecto de la siguiente manera:
```
distributed-fs/
├── master/
│   ├── main.go          // Nodo maestro
│   └── metadata.go      // Gestión de metadatos
├── storage/
│   ├── main.go          // Nodo de almacenamiento
│   └── file_handler.go  // Manejo de archivos
├── client/
│   └── main.go          // Cliente para interactuar con el sistema
└── utils/
    └── network.go       // Funciones comunes de red
```

#### **3.2. Nodo Maestro**
El nodo maestro es responsable de:
- Mantener un registro de los nodos de almacenamiento disponibles.
- Asignar archivos a nodos específicos.
- Gestionar la replicación.

**Ejemplo de código (`master/main.go`):**
```go
package main

import (
	"encoding/json"
	"fmt"
	"net/http"
	"sync"
)

type Node struct {
	ID   string `json:"id"`
	Addr string `json:"addr"`
}

type Metadata struct {
	FileToNodes map[string][]string `json:"file_to_nodes"`
}

var (
	nodes     = make(map[string]Node)
	metadata  = Metadata{FileToNodes: make(map[string][]string)}
	mu        sync.Mutex
	nodeCount = 0
)

func registerNode(w http.ResponseWriter, r *http.Request) {
	mu.Lock()
	defer mu.Unlock()

	var node Node
	if err := json.NewDecoder(r.Body).Decode(&node); err != nil {
		http.Error(w, "Invalid request", http.StatusBadRequest)
		return
	}

	nodeCount++
	node.ID = fmt.Sprintf("node-%d", nodeCount)
	nodes[node.ID] = node

	fmt.Fprintf(w, "Node registered: %s\n", node.ID)
}

func getFileLocations(w http.ResponseWriter, r *http.Request) {
	filename := r.URL.Query().Get("filename")
	if filename == "" {
		http.Error(w, "Missing filename", http.StatusBadRequest)
		return
	}

	mu.Lock()
	defer mu.Unlock()

	nodes, exists := metadata.FileToNodes[filename]
	if !exists {
		http.Error(w, "File not found", http.StatusNotFound)
		return
	}

	json.NewEncoder(w).Encode(nodes)
}

func main() {
	http.HandleFunc("/register", registerNode)
	http.HandleFunc("/locations", getFileLocations)

	fmt.Println("Master node running on :8080")
	http.ListenAndServe(":8080", nil)
}
```

#### **3.3. Nodo de Almacenamiento**
Los nodos de almacenamiento son responsables de:
- Almacenar fragmentos de archivos.
- Responder a solicitudes de descarga.

**Ejemplo de código (`storage/main.go`):**
```go
package main

import (
	"fmt"
	"io/ioutil"
	"net/http"
	"os"
	"path/filepath"
)

const storageDir = "./storage"

func uploadFile(w http.ResponseWriter, r *http.Request) {
	r.ParseMultipartForm(10 << 20) // Límite de 10 MB
	file, handler, err := r.FormFile("file")
	if err != nil {
		http.Error(w, "Unable to read file", http.StatusBadRequest)
		return
	}
	defer file.Close()

	os.MkdirAll(storageDir, os.ModePerm)
	filePath := filepath.Join(storageDir, handler.Filename)
	out, err := os.Create(filePath)
	if err != nil {
		http.Error(w, "Unable to create file", http.StatusInternalServerError)
		return
	}
	defer out.Close()

	_, err = out.ReadFrom(file)
	if err != nil {
		http.Error(w, "Unable to save file", http.StatusInternalServerError)
		return
	}

	fmt.Fprintf(w, "File uploaded: %s\n", handler.Filename)
}

func downloadFile(w http.ResponseWriter, r *http.Request) {
	filename := r.URL.Query().Get("filename")
	if filename == "" {
		http.Error(w, "Missing filename", http.StatusBadRequest)
		return
	}

	filePath := filepath.Join(storageDir, filename)
	data, err := ioutil.ReadFile(filePath)
	if err != nil {
		http.Error(w, "File not found", http.StatusNotFound)
		return
	}

	w.Header().Set("Content-Disposition", fmt.Sprintf("attachment; filename=%s", filename))
	w.Write(data)
}

func main() {
	http.HandleFunc("/upload", uploadFile)
	http.HandleFunc("/download", downloadFile)

	fmt.Println("Storage node running on :8081")
	http.ListenAndServe(":8081", nil)
}
```

#### **3.4. Cliente**
El cliente interactúa con el sistema para subir y descargar archivos.

**Ejemplo de código (`client/main.go`):**
```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"os"
)

func uploadFile(filename, masterAddr string) {
	file, err := os.Open(filename)
	if err != nil {
		fmt.Println("Error opening file:", err)
		return
	}
	defer file.Close()

	body := &bytes.Buffer{}
	writer := multipart.NewWriter(body)
	part, err := writer.CreateFormFile("file", filename)
	if err != nil {
		fmt.Println("Error creating form file:", err)
		return
	}
	io.Copy(part, file)
	writer.Close()

	resp, err := http.Post(fmt.Sprintf("http://%s/upload", masterAddr), writer.FormDataContentType(), body)
	if err != nil {
		fmt.Println("Error uploading file:", err)
		return
	}
	defer resp.Body.Close()

	fmt.Println("File uploaded successfully")
}

func downloadFile(filename, masterAddr string) {
	resp, err := http.Get(fmt.Sprintf("http://%s/download?filename=%s", masterAddr, filename))
	if err != nil {
		fmt.Println("Error downloading file:", err)
		return
	}
	defer resp.Body.Close()

	out, err := os.Create(filename)
	if err != nil {
		fmt.Println("Error creating file:", err)
		return
	}
	defer out.Close()

	io.Copy(out, resp.Body)
	fmt.Println("File downloaded successfully")
}

func main() {
	// Ejemplo de uso
	uploadFile("example.txt", "localhost:8081")
	downloadFile("example.txt", "localhost:8081")
}
```

```java
package master;

import java.io.*;
import java.net.*;
import java.util.*;

public class MasterNode {
    private static Map<String, List<String>> fileToNodes = new HashMap<>();
    private static Map<String, String> nodes = new HashMap<>();
    private static int nodeCount = 0;

    public static void main(String[] args) throws IOException {
        ServerSocket serverSocket = new ServerSocket(8080);
        System.out.println("Master node running on port 8080");

        while (true) {
            Socket socket = serverSocket.accept();
            new Thread(() -> handleRequest(socket)).start();
        }
    }

    private static void handleRequest(Socket socket) {
        try (BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
             PrintWriter out = new PrintWriter(socket.getOutputStream(), true)) {

            String request = in.readLine();
            if (request.startsWith("REGISTER")) {
                String addr = request.split(" ")[1];
                nodeCount++;
                String nodeId = "node-" + nodeCount;
                nodes.put(nodeId, addr);
                out.println("Node registered: " + nodeId);
            } else if (request.startsWith("LOCATIONS")) {
                String filename = request.split(" ")[1];
                List<String> locations = fileToNodes.getOrDefault(filename, Collections.emptyList());
                out.println(locations.toString());
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

#### **3.3. Nodo de Almacenamiento**
Los nodos de almacenamiento son responsables de:

**Ejemplo de código (`storage/StorageNode.java`):**
```java
package storage;

import java.io.*;
import java.net.*;
import java.nio.file.*;

public class StorageNode {
    private static final String STORAGE_DIR = "./storage/";

    public static void main(String[] args) throws IOException {
        Files.createDirectories(Paths.get(STORAGE_DIR));
        ServerSocket serverSocket = new ServerSocket(8081);
        System.out.println("Storage node running on port 8081");

        while (true) {
            Socket socket = serverSocket.accept();
            new Thread(() -> handleRequest(socket)).start();
        }
    }

    private static void handleRequest(Socket socket) {
        try (BufferedReader in = new BufferedReader(new InputStreamReader(socket.getInputStream()));
             OutputStream out = socket.getOutputStream()) {

            String request = in.readLine();
            if (request.startsWith("UPLOAD")) {
                String filename = request.split(" ")[1];
                Path filePath = Paths.get(STORAGE_DIR + filename);
                Files.copy(socket.getInputStream(), filePath, StandardCopyOption.REPLACE_EXISTING);
                System.out.println("File uploaded: " + filename);
            } else if (request.startsWith("DOWNLOAD")) {
                String filename = request.split(" ")[1];
                Path filePath = Paths.get(STORAGE_DIR + filename);
                if (Files.exists(filePath)) {
                    Files.copy(filePath, out);
                    System.out.println("File downloaded: " + filename);
                } else {
                    System.out.println("File not found: " + filename);
                }
            }
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

## Cómo crear un sistema de almacenamiento de archivos distribuido usando Java con java http server y virtual trheads 



Crear un sistema de almacenamiento de archivos distribuido utilizando Java, el servidor HTTP integrado (`com.sun.net.httpserver.HttpServer`) y virtual threads (introducidos en Java 19) es un proyecto interesante que combina conceptos de redes, concurrencia y sistemas distribuidos. A continuación, se describe un enfoque paso a paso para implementar este sistema.

---

### **1. Requisitos del Sistema**
El sistema debe cumplir con los siguientes objetivos:
- Permitir la carga (`upload`) y descarga (`download`) de archivos.
- Distribuir los archivos entre varios nodos (servidores).
- Usar virtual threads para manejar múltiples solicitudes concurrentes de manera eficiente.
- Proporcionar una API REST simple para interactuar con el sistema.

---

### **2. Arquitectura del Sistema**
El sistema constará de:
1. **Nodos de Almacenamiento**: Cada nodo es un servidor HTTP que almacena archivos localmente.
2. **Servidor Coordinador**: Un servidor central que gestiona la distribución de archivos entre los nodos.
3. **Cliente**: Una aplicación o herramienta que interactúa con el sistema para cargar y descargar archivos.

---

### **3. Implementación Paso a Paso**

#### **3.1. Configuración del Proyecto**
Asegúrate de usar Java 19 o superior para aprovechar las virtual threads. Puedes usar Maven o Gradle para gestionar las dependencias.

#### **3.2. Nodo de Almacenamiento**
Cada nodo será un servidor HTTP que maneja solicitudes para almacenar y recuperar archivos.

```java
import com.sun.net.httpserver.HttpServer;
import java.io.*;
import java.net.InetSocketAddress;
import java.nio.file.*;

public class StorageNode {
    private final int port;
    private final String storageDir;

    public StorageNode(int port, String storageDir) {
        this.port = port;
        this.storageDir = storageDir;
        try {
            Files.createDirectories(Paths.get(storageDir));
        } catch (IOException e) {
            throw new RuntimeException("Error creating storage directory", e);
        }
    }

    public void start() throws IOException {
        HttpServer server = HttpServer.create(new InetSocketAddress(port), 0);
        server.createContext("/upload", exchange -> {
            if ("POST".equals(exchange.getRequestMethod())) {
                try (InputStream inputStream = exchange.getRequestBody()) {
                    String fileName = exchange.getRequestHeaders().getFirst("File-Name");
                    Path filePath = Paths.get(storageDir, fileName);
                    Files.copy(inputStream, filePath, StandardCopyOption.REPLACE_EXISTING);
                    exchange.sendResponseHeaders(200, -1); // Respuesta OK sin cuerpo
                } catch (Exception e) {
                    exchange.sendResponseHeaders(500, -1); // Error interno
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        });

        server.createContext("/download", exchange -> {
            if ("GET".equals(exchange.getRequestMethod())) {
                String fileName = exchange.getRequestURI().getQuery().split("=")[1];
                Path filePath = Paths.get(storageDir, fileName);
                if (Files.exists(filePath)) {
                    exchange.sendResponseHeaders(200, Files.size(filePath));
                    try (OutputStream outputStream = exchange.getResponseBody();
                         InputStream fileStream = Files.newInputStream(filePath)) {
                        fileStream.transferTo(outputStream);
                    }
                } else {
                    exchange.sendResponseHeaders(404, -1); // Archivo no encontrado
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        });

        server.setExecutor(null); // Usa el executor por defecto (thread pool)
        server.start();
        System.out.println("Storage node running on port " + port);
    }

    public static void main(String[] args) throws IOException {
        new StorageNode(8081, "storage").start();
    }
}
```

#### **3.3. Servidor Coordinador**
El coordinador decide en qué nodo almacenar un archivo y redirige las solicitudes.

```java
import com.sun.net.httpserver.HttpServer;
import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.InetSocketAddress;
import java.net.URL;
import java.util.List;

public class Coordinator {
    private final List<String> nodes; // Lista de URLs de los nodos

    public Coordinator(List<String> nodes) {
        this.nodes = nodes;
    }

    public void start() throws IOException {
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/upload", exchange -> {
            if ("POST".equals(exchange.getRequestMethod())) {
                String fileName = exchange.getRequestHeaders().getFirst("File-Name");
                String targetNode = nodes.get(Math.abs(fileName.hashCode()) % nodes.size());
                forwardRequest(targetNode + "/upload", exchange, "POST", fileName);
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        });

        server.createContext("/download", exchange -> {
            if ("GET".equals(exchange.getRequestMethod())) {
                String fileName = exchange.getRequestURI().getQuery().split("=")[1];
                String targetNode = nodes.get(Math.abs(fileName.hashCode()) % nodes.size());
                forwardRequest(targetNode + "/download?file=" + fileName, exchange, "GET", null);
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        });

        server.setExecutor(null); // Usa el executor por defecto
        server.start();
        System.out.println("Coordinator running on port 8080");
    }

    private void forwardRequest(String targetUrl, HttpExchange exchange, String method, String fileName) {
        try {
            URL url = new URL(targetUrl);
            HttpURLConnection connection = (HttpURLConnection) url.openConnection();
            connection.setRequestMethod(method);
            if ("POST".equals(method)) {
                connection.setDoOutput(true);
                connection.setRequestProperty("File-Name", fileName);
                try (OutputStream outputStream = connection.getOutputStream()) {
                    exchange.getRequestBody().transferTo(outputStream);
                }
            }
            exchange.sendResponseHeaders(connection.getResponseCode(), connection.getContentLengthLong());
            try (InputStream inputStream = connection.getInputStream();
                 OutputStream outputStream = exchange.getResponseBody()) {
                inputStream.transferTo(outputStream);
            }
        } catch (Exception e) {
            exchange.sendResponseHeaders(500, -1); // Error interno
        }
    }

    public static void main(String[] args) throws IOException {
        new Coordinator(List.of("http://localhost:8081", "http://localhost:8082")).start();
    }
}
```

#### **3.4. Cliente**
Un cliente simple para interactuar con el sistema.

```java
import java.io.*;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.file.*;

public class Client {
    public static void uploadFile(String coordinatorUrl, String filePath) throws IOException {
        File file = new File(filePath);
        URL url = new URL(coordinatorUrl + "/upload");
        HttpURLConnection connection = (HttpURLConnection) url.openConnection();
        connection.setRequestMethod("POST");
        connection.setDoOutput(true);
        connection.setRequestProperty("File-Name", file.getName());

        try (OutputStream outputStream = connection.getOutputStream();
             InputStream fileStream = Files.newInputStream(file.toPath())) {
            fileStream.transferTo(outputStream);
        }

        if (connection.getResponseCode() == 200) {
            System.out.println("File uploaded successfully.");
        } else {
            System.out.println("Failed to upload file.");
        }
    }

    public static void downloadFile(String coordinatorUrl, String fileName, String outputPath) throws IOException {
        URL url = new URL(coordinatorUrl + "/download?file=" + fileName);
        HttpURLConnection connection = (HttpURLConnection) url.openConnection();
        connection.setRequestMethod("GET");

        if (connection.getResponseCode() == 200) {
            try (InputStream inputStream = connection.getInputStream();
                 OutputStream outputStream = Files.newOutputStream(Paths.get(outputPath))) {
                inputStream.transferTo(outputStream);
                System.out.println("File downloaded successfully.");
            }
        } else {
            System.out.println("Failed to download file.");
        }
    }

    public static void main(String[] args) throws IOException {
        String coordinatorUrl = "http://localhost:8080";
        uploadFile(coordinatorUrl, "example.txt");
        downloadFile(coordinatorUrl, "example.txt", "downloaded_example.txt");
    }
}
```

### **4. Uso de Virtual Threads**
Para mejorar la concurrencia, puedes reemplazar el `executor` predeterminado del servidor HTTP con un `Executor` que use virtual threads:

```java
server.setExecutor(Executors.newVirtualThreadPerTaskExecutor());
```

Esto asegura que cada solicitud se maneje en una virtual thread, lo que reduce el overhead asociado con las threads tradicionales.
