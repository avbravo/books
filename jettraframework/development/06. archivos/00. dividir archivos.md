dividir archivos en Java 


A continuación, te muestro un programa en Java que divide un archivo grande en pequeños archivos y luego los une nuevamente. Este programa utiliza la biblioteca estándar de Java (`java.io` y `java.nio`) para manejar archivos.

### Código: Dividir y Unir Archivos

```java
import java.io.*;
import java.nio.file.*;

public class FileSplitter {

    // Método para dividir un archivo en partes más pequeñas
    public static void splitFile(File inputFile, String outputDir, int chunkSize) throws IOException {
        if (!Files.exists(Paths.get(outputDir))) {
            Files.createDirectories(Paths.get(outputDir));
        }

        try (BufferedInputStream inputStream = new BufferedInputStream(new FileInputStream(inputFile))) {
            byte[] buffer = new byte[chunkSize];
            int bytesRead;
            int partNumber = 1;

            while ((bytesRead = inputStream.read(buffer)) > 0) {
                // Crear un nuevo archivo para cada parte
                File outputFile = new File(outputDir, inputFile.getName() + ".part" + partNumber);
                try (BufferedOutputStream outputStream = new BufferedOutputStream(new FileOutputStream(outputFile))) {
                    outputStream.write(buffer, 0, bytesRead);
                }
                partNumber++;
            }
        }
    }

    // Método para unir los archivos divididos en un solo archivo
    public static void mergeFiles(String inputDir, String outputFilePath) throws IOException {
        try (BufferedOutputStream outputStream = new BufferedOutputStream(new FileOutputStream(outputFilePath))) {
            int partNumber = 1;
            File inputFile;

            while ((inputFile = new File(inputDir, new File(outputFilePath).getName() + ".part" + partNumber)).exists()) {
                try (BufferedInputStream inputStream = new BufferedInputStream(new FileInputStream(inputFile))) {
                    byte[] buffer = new byte[1024];
                    int bytesRead;

                    while ((bytesRead = inputStream.read(buffer)) > 0) {
                        outputStream.write(buffer, 0, bytesRead);
                    }
                }
                partNumber++;
            }
        }
    }

    public static void main(String[] args) {
        try {
            // Ruta del archivo a dividir
            File inputFile = new File("archivo.txt");
            String outputDir = "partes_divididas";
            int chunkSize = 1024 * 1024; // Tamaño de cada parte (1 MB)

            // Dividir el archivo
            System.out.println("Dividiendo archivo...");
            splitFile(inputFile, outputDir, chunkSize);
            System.out.println("Archivo dividido exitosamente en partes.");

            // Unir los archivos
            String outputFilePath = "archivo_unido.txt";
            System.out.println("Uniendo partes...");
            mergeFiles(outputDir, outputFilePath);
            System.out.println("Archivos unidos exitosamente en: " + outputFilePath);

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}
```

### Explicación del Código

#### **1. División del Archivo**
- El método `splitFile` toma como entrada:
  - `inputFile`: El archivo que se desea dividir.
  - `outputDir`: El directorio donde se guardarán las partes divididas.
  - `chunkSize`: El tamaño máximo de cada parte (en bytes).
- El archivo se lee en bloques de tamaño `chunkSize` utilizando un `BufferedInputStream`.
- Cada bloque se escribe en un archivo separado con nombres como `archivo.txt.part1`, `archivo.txt.part2`, etc.
- Los archivos resultantes se almacenan en el directorio especificado por `outputDir`.

#### **2. Unión de los Archivos**
- El método `mergeFiles` toma como entrada:
  - `inputDir`: El directorio donde están almacenadas las partes divididas.
  - `outputFilePath`: La ruta del archivo final después de la unión.
- Se asume que los archivos divididos tienen nombres consecutivos (`archivo.txt.part1`, `archivo.txt.part2`, etc.).
- Cada archivo se lee secuencialmente utilizando un `BufferedInputStream` y se escribe en el archivo de salida utilizando un `BufferedOutputStream`.

#### **3. Ejecución Principal**
- En el método `main`, se define:
  - `inputFile`: El archivo que se desea dividir.
  - `outputDir`: El directorio donde se guardarán las partes divididas.
  - `chunkSize`: El tamaño de cada parte (en este caso, 1 MB).
- Primero, se llama al método `splitFile` para dividir el archivo.
- Luego, se llama al método `mergeFiles` para unir las partes en un archivo final.

import java.io.*;

public class FileSplitter {

    // Método para dividir un archivo en partes más pequeñas

    // Método para unir los archivos divididos en un solo archivo
    public static void mergeFiles(String inputDir, String outputFilePath) throws IOException {
        try (BufferedOutputStream outputStream = new BufferedOutputStream(new FileOutputStream(outputFilePath))) {
            int partNumber = 1;
            File inputFile;

            while ((inputFile = new File(inputDir, new File(outputFilePath).getName() + ".part" + partNumber)).exists()) {
                try (BufferedInputStream inputStream = new BufferedInputStream(new FileInputStream(inputFile))) {
                    byte[] buffer = new byte[1024];
                    int bytesRead;

                    while ((bytesRead = inputStream.read(buffer)) > 0) {
                        outputStream.write(buffer, 0, bytesRead);
                    }
                }
                System.out.println("Parte " + partNumber + " unida: " + inputFile.getName());
                partNumber++;
            }
        }
    }

    // Método principal
    public static void main(String[] args) {
        try {
            // Configuración inicial
            String fileName = "archivo.pdf"; // Cambia esto al nombre de tu archivo (PDF, DOCX, imagen, etc.)
            File inputFile = new File(fileName);
            String outputDir = "partes_divididas";
            String outputFilePath = "archivo_unido." + getFileExtension(fileName); // Mantener la extensión original
            int chunkSize = 1024 * 1024; // Tamaño de cada parte (1 MB)

            // Validar que el archivo exista
            if (!inputFile.exists()) {
                System.out.println("El archivo no existe: " + inputFile.getAbsolutePath());
                return;
            }

            // Dividir el archivo
            System.out.println("Dividiendo archivo...");

        }
    }

    // Método auxiliar para obtener la extensión de un archivo
    private static String getFileExtension(String fileName) {
        int lastIndex = fileName.lastIndexOf('.');
        if (lastIndex == -1) {
            return ""; // No hay extensión
        }
        return fileName.substring(lastIndex + 1);
    }
