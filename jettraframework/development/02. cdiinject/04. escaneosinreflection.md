
Realizar un escaneo automático de clases sin usar una biblioteca como Reflections implica implementar manualmente la búsqueda de clases en los paquetes especificados. Esto se puede lograr utilizando las APIs estándar de Java, como `ClassLoader` y el sistema de archivos para explorar los archivos `.class` dentro del classpath.

A continuación, te muestro cómo implementar un escáner automático sin usar Reflections:

---

### Paso 1: Implementar el Escáner de Clases
El escáner buscará todas las clases en un paquete específico y verificará si están anotadas con `@Singleton` o `@Prototype`.

```java
import java.io.File;
import java.io.IOException;
import java.net.URL;
import java.util.ArrayList;
import java.util.Enumeration;
import java.util.List;

public class ClassScanner {

    /**
     * Escanea un paquete y devuelve todas las clases encontradas.
     *
     * @param packageName El nombre del paquete a escanear.
     * @return Una lista de clases encontradas en el paquete.
     */
    public static List<Class<?>> scanPackage(String packageName) {
        List<Class<?>> classes = new ArrayList<>();
        String packagePath = packageName.replace('.', '/');
        ClassLoader classLoader = Thread.currentThread().getContextClassLoader();

        try {
            Enumeration<URL> resources = classLoader.getResources(packagePath);
            while (resources.hasMoreElements()) {
                URL resource = resources.nextElement();
                File directory = new File(resource.getFile());

                if (directory.exists()) {
                    // Si es un directorio, recorre los archivos .class
                    findClassesInDirectory(directory, packageName, classes);
                } else {
                    // Si es un archivo JAR, procesarlo (no implementado aquí)
                    System.out.println("JAR files are not supported in this example.");
                }
            }
        } catch (IOException e) {
            throw new RuntimeException("Failed to scan package: " + packageName, e);
        }

        return classes;
    }

    /**
     * Busca clases en un directorio recursivamente.
     *
     * @param directory   El directorio actual.
     * @param packageName El nombre del paquete.
     * @param classes     La lista donde se agregan las clases encontradas.
     */
    private static void findClassesInDirectory(File directory, String packageName, List<Class<?>> classes) {
        File[] files = directory.listFiles();
        if (files == null) {
            return;
        }

        for (File file : files) {
            if (file.isDirectory()) {
                // Si es un subdirectorio, continúa buscando recursivamente
                findClassesInDirectory(file, packageName + "." + file.getName(), classes);
            } else if (file.getName().endsWith(".class")) {
                // Si es un archivo .class, carga la clase
                String className = packageName + '.' + file.getName().substring(0, file.getName().length() - 6);
                try {
                    Class<?> clazz = Class.forName(className);
                    classes.add(clazz);
                } catch (ClassNotFoundException e) {
                    throw new RuntimeException("Failed to load class: " + className, e);
                }
            }
        }
    }
}
```

### Paso 2: Modificar el `BeanContainer`
Actualizamos el `BeanContainer` para usar el escáner de clases y registrar automáticamente las clases anotadas.

```java
import java.util.HashMap;
import java.util.List;
import java.util.Map;

public class BeanContainer {
    private final Map<Class<?>, Object> singletonBeans = new HashMap<>();
    private final Map<Class<?>, Class<?>> beanDefinitions = new HashMap<>();

    /**
     * Escanea un paquete y registra automáticamente las clases anotadas.
     *
     * @param packageName El nombre del paquete a escanear.
     */
    public void scanAndRegister(String packageName) {
        List<Class<?>> classes = ClassScanner.scanPackage(packageName);

        for (Class<?> clazz : classes) {
            if (clazz.isAnnotationPresent(Singleton.class) || clazz.isAnnotationPresent(Prototype.class)) {
                registerBean(clazz);
            }
        }
    }

    public void registerBean(Class<?> beanClass) {
        if (beanClass.isInterface()) {
            throw new IllegalArgumentException("Cannot register an interface directly: " + beanClass.getName());
        }
        beanDefinitions.put(beanClass, beanClass);

        // Si la clase implementa una interfaz, registramos la relación
        for (Class<?> iface : beanClass.getInterfaces()) {
            beanDefinitions.put(iface, beanClass);
        }
    }

    public <T> T getBean(Class<T> beanClass) {
        Class<?> implementationClass = beanDefinitions.get(beanClass);
        if (implementationClass == null) {
            throw new RuntimeException("No implementation found for: " + beanClass.getName());
        }

        if (implementationClass.isAnnotationPresent(Singleton.class)) {
            return getSingletonBean(implementationClass);
        } else {
            return createNewInstance(implementationClass);
        }
    }

    @SuppressWarnings("unchecked")
    private <T> T getSingletonBean(Class<?> beanClass) {
        return (T) singletonBeans.computeIfAbsent(beanClass, this::createNewInstance);
    }

    @SuppressWarnings("unchecked")
    private <T> T createNewInstance(Class<?> beanClass) {
        try {
            T instance = (T) beanClass.getDeclaredConstructor().newInstance();
            injectDependencies(instance);
            return instance;
        } catch (Exception e) {
            throw new RuntimeException("Failed to create bean: " + beanClass.getName(), e);
        }
    }

    private <T> void injectDependencies(T instance) {
        for (var field : instance.getClass().getDeclaredFields()) {
            if (field.isAnnotationPresent(Inject.class)) {
                field.setAccessible(true);
                Class<?> fieldType = field.getType();
                Object dependency = getBean(fieldType);
                try {
                    field.set(instance, dependency);
                } catch (IllegalAccessException e) {
                    throw new RuntimeException("Failed to inject dependency: " + field.getName(), e);
                }
            }
        }
    }
}
```

### Paso 3: Usar el Escáner Automático
Ahora podemos usar el método `scanAndRegister` para registrar automáticamente todas las clases anotadas en un paquete específico.

```java
public class Main {
    public static void main(String[] args) {
        BeanContainer container = new BeanContainer();

        // Escanear y registrar automáticamente todas las clases anotadas en el paquete "com.example"
        container.scanAndRegister("com.example");

        // Obtener beans
        UserService userService = container.getBean(UserService.class);
        userService.addUser("Alice");
        userService.getUser("123");

        // Verificar que el servicio es prototype-scoped
        UserService userService2 = container.getBean(UserService.class);
        System.out.println("Are userService and userService2 the same instance? " + (userService == userService2));
    }
}
```

---

### Salida Esperada
Cuando ejecutas el programa, la salida será:

```
Saving user: Alice
Finding user with ID: 123
Retrieved user: User-123
Are userService and userService2 the same instance? false
```

---

### Explicación del Funcionamiento
1. **Escaneo Manual**: El `ClassScanner` busca todos los archivos `.class` en el paquete especificado y carga las clases usando `Class.forName`.
2. **Filtrado por Anotaciones**: Solo se registran las clases anotadas con `@Singleton` o `@Prototype`.
3. **Registro Automático**: Las clases encontradas se registran automáticamente en el `BeanContainer`.
4. **Resolución de Interfaces**: Si una clase implementa una interfaz, el contenedor asocia la interfaz con la implementación.

---

### Ventajas
- **Sin Dependencias Externas**: No usamos bibliotecas externas como Reflections.
- **Control Total**: Tienes control completo sobre cómo se escanean y registran las clases.
- **Compatibilidad**: Funciona en cualquier entorno Java SE.

---

### Limitaciones
1. **Archivos JAR**: Este ejemplo no maneja archivos JAR. Para soportar JARs, necesitarías extender el escáner para procesar entradas ZIP.
2. **Performance**: Escanear grandes paquetes puede ser lento, especialmente si hay muchos archivos `.class`.
3. **Seguridad**: Algunos entornos restringen el acceso al sistema de archivos o al classpath.

Si necesitas más detalles o mejoras, ¡házmelo saber!
