
A continuación, te muestro cómo invocar los endpoints del ejemplo utilizando **`curl`**. Cada comando incluye la URL, el método HTTP (`POST` o `GET`) y, en algunos casos, datos enviados en el cuerpo de la solicitud.

curl -X POST http://localhost:8080/users/add -H "Content-Type: application/json" -d '{"name": "Alice"}' 


curl -X GET "http://localhost:8080/users/get?id='a'"



---

### 1. Agregar un Usuario (`POST /users/add`)
Este endpoint agrega un usuario al sistema. El nombre del usuario se envía en el cuerpo de la solicitud.

#### Comando `curl`
```bash
curl -X POST http://localhost:8080/users/add -d "Alice"
```

#### Salida Esperada
El servidor imprimirá:
```
Saving user: Alice
```

Y la respuesta será:
```
User added: Alice
```

---

### 2. Obtener un Usuario (`GET /users/get`)
Este endpoint recupera un usuario por su ID. El ID se pasa como un parámetro de consulta en la URL.

#### Comando `curl`
```bash
curl -X GET "http://localhost:8080/users/get?id=a"
```

#### Salida Esperada
El servidor imprimirá:
```
Finding user with ID: 123
Retrieved user: User-123
```

Y la respuesta será:
```
Retrieved user: User-123
```

---

### 3. Agregar un País (`POST /countries/add`)
Este endpoint agrega un país al sistema. El nombre del país se envía en el cuerpo de la solicitud.

#### Comando `curl`
```bash
curl -X POST http://localhost:8080/countries/add -d "Mexico"
```

#### Salida Esperada
El servidor imprimirá:
```
Saving country: Mexico
```

Y la respuesta será:
```
Country added: Mexico
```

---

### 4. Obtener un País (`GET /countries/get`)
Este endpoint recupera un país por su ID. El ID se pasa como un parámetro de consulta en la URL.

#### Comando `curl`
```bash
curl -X GET "http://localhost:8080/countries/get?id=MX"
```

#### Salida Esperada
El servidor imprimirá:
```
Finding country with ID: MX
Retrieved country: Country-MX
```

Y la respuesta será:
```
Retrieved country: Country-MX
```

### Notas Adicionales
1. **Método Incorrecto**: Si intentas usar un método HTTP incorrecto (por ejemplo, `GET` en lugar de `POST`), recibirás una respuesta de error con código `400 Bad Request`.

   Ejemplo:
   ```bash
   curl -X GET http://localhost:8080/users/add
   ```

   Respuesta:
   ```
   Invalid request method. Use POST.
   ```

2. **Parámetros Faltantes**: Si no proporcionas un parámetro necesario (por ejemplo, el `id` en `/users/get`), el servidor podría fallar o devolver un error. Asegúrate de incluir todos los parámetros requeridos.

3. **Formato JSON**: Si deseas enviar datos en formato JSON en lugar de texto plano, puedes modificar los endpoints para aceptar JSON. Por ejemplo:
   ```bash
   curl -X POST http://localhost:8080/users/add -H "Content-Type: application/json" -d '{"id":"1-2","name": "Alice"}'
   ```


```bash
curl -X GET "http://localhost:8080/users/get?id=1-2"
``
