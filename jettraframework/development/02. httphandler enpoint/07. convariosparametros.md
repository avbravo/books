A continuación, se presenta un ejemplo de un programa Java que utiliza `HttpHandler` para manejar solicitudes HTTP y define varios métodos GET con múltiples parámetros. Este ejemplo utiliza el paquete `com.sun.net.httpserver`, que es parte del JDK estándar.

### Código completo:

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.util.HashMap;
import java.util.Map;

public class MultiParamHttpServer {

    public static void main(String[] args) throws IOException {
        // Crear un servidor HTTP en el puerto 8080
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);

        // Definir rutas y sus manejadores
        server.createContext("/get1", new GetHandler1());
        server.createContext("/get2", new GetHandler2());
        server.createContext("/get3", new GetHandler3());

        // Iniciar el servidor
        server.setExecutor(null); // Usa el executor por defecto
        server.start();
        System.out.println("Servidor iniciado en http://localhost:8080");
    }

    // Manejador para /get1
    static class GetHandler1 implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                // Parsear los parámetros de la URL
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());

                // Obtener los valores de los parámetros
                String param1 = params.getOrDefault("param1", "default1");
                String param2 = params.getOrDefault("param2", "default2");

                // Construir la respuesta
                String response = "Respuesta desde /get1:\n" +
                                  "param1: " + param1 + "\n" +
                                  "param2: " + param2;

                // Enviar la respuesta
                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Manejador para /get2
    static class GetHandler2 implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());

                String name = params.getOrDefault("name", "Guest");
                String age = params.getOrDefault("age", "Unknown");

                String response = "Respuesta desde /get2:\n" +
                                  "Hola, " + name + "!\n" +
                                  "Tu edad es: " + age;

                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Manejador para /get3
    static class GetHandler3 implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());

                String item = params.getOrDefault("item", "N/A");
                String quantity = params.getOrDefault("quantity", "0");

                String response = "Respuesta desde /get3:\n" +
                                  "Item: " + item + "\n" +
                                  "Cantidad: " + quantity;

                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Método auxiliar para parsear los parámetros de la URL
    private static Map<String, String> parseQuery(String query) {
        Map<String, String> result = new HashMap<>();
        if (query == null) return result;

        for (String param : query.split("&")) {
            String[] pair = param.split("=");
            if (pair.length > 1) {
                result.put(pair[0], pair[1]);
            } else {
                result.put(pair[0], "");
            }
        }
        return result;
    }
}
```

---

### Explicación del código:

1. **Creación del servidor HTTP**:
   - Se crea una instancia de `HttpServer` en el puerto `8080`.
   - Se definen tres contextos (`/get1`, `/get2`, `/get3`) con sus respectivos manejadores.

2. **Manejadores personalizados**:
   - Cada ruta tiene su propio manejador (`GetHandler1`, `GetHandler2`, `GetHandler3`).
   - Los manejadores procesan las solicitudes GET y extraen los parámetros de la URL utilizando el método `parseQuery`.

3. **Procesamiento de parámetros**:
   - Los parámetros se obtienen de la consulta (`?param1=value1&param2=value2`) y se almacenan en un `Map`.
   - Si un parámetro no está presente, se utiliza un valor predeterminado.

4. **Envío de respuestas**:
   - La respuesta se construye como una cadena y se envía al cliente con un código de estado `200 OK`.
   - Si el método HTTP no es GET, se devuelve un código de estado `405 Method Not Allowed`.

5. **Método auxiliar `parseQuery`**:
   - Este método divide la cadena de consulta en pares clave-valor y los almacena en un `HashMap`.

### Ejemplo de uso:

1. Inicia el servidor ejecutando el programa.
2. Realiza las siguientes solicitudes en tu navegador o usando `curl`:

   - **Solicitud 1**:  
     ```
     http://localhost:8080/get1?param1=valor1&param2=valor2
     ```
     Respuesta:
     ```
     Respuesta desde /get1:
     param1: valor1
     param2: valor2
     ```

   - **Solicitud 2**:  
     ```
     http://localhost:8080/get2?name=Juan&age=25
     ```
     Respuesta:
     ```
     Respuesta desde /get2:
     Hola, Juan!
     Tu edad es: 25
     ```

   - **Solicitud 3**:  
     ```
     http://localhost:8080/get3?item=Laptop&quantity=3
     ```
     Respuesta:
     ```
     Respuesta desde /get3:
     Item: Laptop
     Cantidad: 3
     ```
