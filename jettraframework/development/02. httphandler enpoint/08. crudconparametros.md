A continuación, se presenta un ejemplo de un programa Java que implementa un CRUD (Create, Read, Update, Delete) para una clase llamada `Persona`. Además, incluye varios métodos GET con diferentes parámetros para interactuar con los datos. Este ejemplo utiliza el paquete `com.sun.net.httpserver` para manejar las solicitudes HTTP.

---

### Código completo:

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
import java.util.*;
import java.util.stream.Collectors;

class Persona {
    private int id;
    private String nombre;
    private int edad;

    public Persona(int id, String nombre, int edad) {
        this.id = id;
        this.nombre = nombre;
        this.edad = edad;
    }

    public int getId() {
        return id;
    }

    public String getNombre() {
        return nombre;
    }

    public int getEdad() {
        return edad;
    }

    @Override
    public String toString() {
        return "Persona{id=" + id + ", nombre='" + nombre + "', edad=" + edad + "}";
    }
}

public class PersonaCRUDHttpServer {

    // Simulación de una base de datos en memoria
    private static Map<Integer, Persona> personasDB = new HashMap<>();
    private static int nextId = 1;

    public static void main(String[] args) throws IOException {
        // Crear un servidor HTTP en el puerto 8080
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);

        // Definir rutas y sus manejadores
        server.createContext("/personas", new PersonaHandler());
        server.createContext("/personas/id", new GetPersonaByIdHandler());
        server.createContext("/personas/nombre", new GetPersonasByNombreHandler());
        server.createContext("/personas/edad", new GetPersonasByEdadHandler());

        // Iniciar el servidor
        server.setExecutor(null); // Usa el executor por defecto
        server.start();
        System.out.println("Servidor iniciado en http://localhost:8080");
    }

    // Manejador principal para el CRUD
    static class PersonaHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            String method = exchange.getRequestMethod();

            if ("POST".equals(method)) {
                // Crear una nueva persona
                Map<String, String> params = parseQuery(exchange.getRequestBody().toString());
                String nombre = params.getOrDefault("nombre", "Desconocido");
                int edad = Integer.parseInt(params.getOrDefault("edad", "0"));

                Persona persona = new Persona(nextId++, nombre, edad);
                personasDB.put(persona.getId(), persona);

                String response = "Persona creada: " + persona.toString();
                exchange.sendResponseHeaders(201, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else if ("GET".equals(method)) {
                // Obtener todas las personas
                String response = "Personas:\n" + personasDB.values().stream()
                        .map(Persona::toString)
                        .collect(Collectors.joining("\n"));
                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else if ("PUT".equals(method)) {
                // Actualizar una persona existente
                Map<String, String> params = parseQuery(exchange.getRequestBody().toString());
                int id = Integer.parseInt(params.getOrDefault("id", "-1"));
                String nombre = params.getOrDefault("nombre", null);
                int edad = Integer.parseInt(params.getOrDefault("edad", "0"));

                Persona persona = personasDB.get(id);
                if (persona != null) {
                    if (nombre != null) persona = new Persona(id, nombre, persona.getEdad());
                    if (edad > 0) persona = new Persona(id, persona.getNombre(), edad);
                    personasDB.put(id, persona);

                    String response = "Persona actualizada: " + persona.toString();
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // No encontrado
                }
            } else if ("DELETE".equals(method)) {
                // Eliminar una persona
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());
                int id = Integer.parseInt(params.getOrDefault("id", "-1"));

                Persona persona = personasDB.remove(id);
                if (persona != null) {
                    String response = "Persona eliminada: " + persona.toString();
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // No encontrado
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Manejador para obtener una persona por ID
    static class GetPersonaByIdHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());
                int id = Integer.parseInt(params.getOrDefault("id", "-1"));

                Persona persona = personasDB.get(id);
                if (persona != null) {
                    String response = "Persona encontrada: " + persona.toString();
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // No encontrado
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Manejador para obtener personas por nombre
    static class GetPersonasByNombreHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());
                String nombre = params.getOrDefault("nombre", "");

                List<Persona> personas = personasDB.values().stream()
                        .filter(p -> p.getNombre().equalsIgnoreCase(nombre))
                        .collect(Collectors.toList());

                if (!personas.isEmpty()) {
                    String response = "Personas encontradas:\n" + personas.stream()
                            .map(Persona::toString)
                            .collect(Collectors.joining("\n"));
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // No encontrado
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Manejador para obtener personas por edad
    static class GetPersonasByEdadHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            if ("GET".equals(exchange.getRequestMethod())) {
                Map<String, String> params = parseQuery(exchange.getRequestURI().getQuery());
                int edad = Integer.parseInt(params.getOrDefault("edad", "-1"));

                List<Persona> personas = personasDB.values().stream()
                        .filter(p -> p.getEdad() == edad)
                        .collect(Collectors.toList());

                if (!personas.isEmpty()) {
                    String response = "Personas encontradas:\n" + personas.stream()
                            .map(Persona::toString)
                            .collect(Collectors.joining("\n"));
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // No encontrado
                }
            } else {
                exchange.sendResponseHeaders(405, -1); // Método no permitido
            }
        }
    }

    // Método auxiliar para parsear los parámetros de la URL o cuerpo de la solicitud
    private static Map<String, String> parseQuery(String query) {
        Map<String, String> result = new HashMap<>();
        if (query == null) return result;

        for (String param : query.split("&")) {
            String[] pair = param.split("=");
            if (pair.length > 1) {
                result.put(pair[0], pair[1]);
            } else {
                result.put(pair[0], "");
            }
        }
        return result;
    }
}
```

---

### Explicación del código:

1. **Clase `Persona`**:
   - Representa una entidad con atributos `id`, `nombre` y `edad`.
   - Incluye un constructor, getters y un método `toString`.

2. **Base de datos en memoria**:
   - Se utiliza un `Map<Integer, Persona>` para almacenar las personas.
   - El `id` es autoincremental.

3. **Manejadores**:
   - `/personas`: Maneja las operaciones CRUD (POST, GET, PUT, DELETE).
   - `/personas/id`: Obtiene una persona por su `id`.
   - `/personas/nombre`: Obtiene personas filtradas por `nombre`.
   - `/personas/edad`: Obtiene personas filtradas por `edad`.

4. **Método auxiliar `parseQuery`**:
   - Parsea los parámetros de la URL o cuerpo de la solicitud.

### Ejemplo de uso:

1. **Crear una persona**:
   ```
   POST http://localhost:8080/personas
   Body: nombre=Juan&edad=25
   ```

2. **Obtener todas las personas**:
   ```
   GET http://localhost:8080/personas
   ```

3. **Obtener una persona por ID**:
   ```
   GET http://localhost:8080/personas/id?id=1
   ```

4. **Obtener personas por nombre**:
   ```
   GET http://localhost:8080/personas/nombre?nombre=Juan
   ```

5. **Obtener personas por edad**:
   ```
   GET http://localhost:8080/personas/edad?edad=25
   ```

6. **Actualizar una persona**:
   ```
   PUT http://localhost:8080/personas
   Body: id=1&nombre=Pedro&edad=30
   ```

7. **Eliminar una persona**:
   ```
   DELETE http://localhost:8080/personas?id=1
   ```
