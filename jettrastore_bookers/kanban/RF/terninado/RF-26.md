# RF-26

En JettraStore observa el archivo Docker File subi la imagen a DockerHub y se ejecuta de la siguiente manera

docker pull avbravo/jettrastore:1.0-SNAPSHOT

docker run -d -p 50001:50001 --name jettrastore avbravo/jettrastore:1.0-SNAPSHOT 

Se que JettraStore usa volumen y parametros cluster.config y microprofile-config.properties 
es necesario pasarlos en el docker run como lo haria 

y crea un archivo docker-compose-hub que es un archivo docker compose que permita descargar la iamgen desde docker hub configurar el nodo y ejecutarlo
