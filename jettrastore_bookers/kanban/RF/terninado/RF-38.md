# RF-38

# Role & Authority
Actúa como arquitecto de software senior en Java 25+ y especialista en motores de almacenamiento distribuido y UI web reactiva para el ecosistema **Jettra** (`JettraStoreDriver`, `JettraStoreShell`, `JettraStoreExplorer`). Tienes autoridad para modificar código fuente, `module-info.java` (cuando aplique), pruebas automatizadas y documentación técnica en `/guide/book.md`.

# Task
Implementar el soporte completo de **Storage Mode** al crear y editar bases de datos en `JettraStoreDriver`, `JettraStoreShell` y `JettraStoreExplorer`, establecer el modo `OFF-HEAP` como predeterminado en la documentación de motores de almacenamiento de los archivos `/guide/book.md`, y actualizar la ayuda (`help`) de `JettraStoreShell` para exigir/indicar la selección del modo de almacenamiento al crear bases de datos.

## Context & Problem Description
Actualmente, la creación y edición de bases de datos no expone ni persiste explícitamente el modo de almacenamiento (`Storage Mode`) a través del driver, la consola interactiva (`JettraStoreShell`) ni el explorador web (`JettraStoreExplorer`). Asimismo, la documentación en `/guide/book.md` necesita reflejar de forma explícita que el modo predeterminado es `OFF-HEAP`, y el comando de ayuda de `JettraStoreShell` debe orientar claramente sobre la selección del modo de almacenamiento al crear una base de datos.

## Technical Requirements & Constraints
- **Stack & Estándares:** Java 25+, Virtual Threads, Records y modularidad JPMS (`module-info.java`) donde corresponda.
- **Pruebas:** Implementar y ejecutar pruebas con **JettraTest** (`JettraTestRunner`). **Prohibido usar JUnit**.
- **UI Web (`JettraStoreExplorer`):** Utilizar exclusivamente **JettraFlux** para componentes de interfaz web. **Prohibido usar HTML/CSS/JS crudo o jQuery**.
- **Modos de Almacenamiento (`Storage Mode`) soportados:**
  1. `JVM-RAM`
  2. `DISK-MEMORY` (Integración nativa con `JettraMemory`)
  3. `OFF-HEAP` (Integración nativa con `JettraStore-OffHeap`) — **Predeterminado**
- **Alcance de módulos:**
  - `JettraStoreDriver`: Exponer y propagar el parámetro/campo de `Storage Mode` en las operaciones de creación y edición de bases de datos, aplicando `OFF-HEAP` por defecto cuando no se especifique explícitamente.
  - `JettraStoreShell`: Permitir seleccionar o indicar el `Storage Mode` (`JVM-RAM`, `DISK-MEMORY`, `OFF-HEAP`) al crear y editar bases de datos, con valor predeterminado `OFF-HEAP`. Actualizar el comando `help` para documentar que al crear una base de datos se debe especificar/seleccionar el tipo de modo de almacenamiento.
  - `JettraStoreExplorer`: En los flujos/formularios de creación y edición de bases de datos (construidos con **JettraFlux**), mostrar la lista de `Storage Mode` (`JVM-RAM`, `DISK-MEMORY`, `OFF-HEAP`) con `OFF-HEAP` preseleccionado por defecto y persistir el cambio al guardar.
- **Documentación (`guide/book.md`):**
  - Revisar todos los archivos `/guide/book.md` en `JettraStoreDriver`, `JettraStoreShell`, `JettraStoreExplorer` (y demás módulos del repositorio si aplica).
  - Localizar todas las secciones donde se mencionan motores de almacenamiento y especificar explícitamente que el modo predeterminado es **`OFF-HEAP`**, documentando también `JVM-RAM` y `DISK-MEMORY`.

## Deliverables
1. Cambios implementados y compilados en `JettraStoreDriver`, `JettraStoreShell` y `JettraStoreExplorer` para creación y edición de bases de datos con `Storage Mode` (`JVM-RAM`, `DISK-MEMORY`, `OFF-HEAP`).
2. Ayuda (`help`) de `JettraStoreShell` actualizada indicando la especificación del modo de almacenamiento al crear una base de datos.
3. Archivos `/guide/book.md` actualizados en cada módulo con el detalle de los tres modos y `OFF-HEAP` como predeterminado.
4. Suite de pruebas con `JettraTestRunner` cubriendo creación, edición, valor por defecto `OFF-HEAP` y actualización de ayuda/configuración.
