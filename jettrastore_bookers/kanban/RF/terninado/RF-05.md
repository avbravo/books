# RF-05

# Especificación funcional y de UI: Simplificación de la vista /explorer y diálogo modal de Estructura del Bucket en JettraStoreExplorer

## Contexto y stack tecnológico
- Proyecto: **JettraStoreExplorer** dentro del ecosistema **JettraStore** (Java 25+, UI reactiva con **JettraFlux**, pruebas con **JettraTest** — sin JUnit).
- Vista objetivo: Página `/explorer` y su documentación en `JettraStoreExplorer/guide/book.md`.

---

## Cambios requeridos en `/explorer`

### 0. Mostrar únicamente la base de datos seleccionada
- En la vista `/explorer`, renderizar **solo la base de datos activa/seleccionada** y su jerarquía de navegación (`Database -> Engine -> Bucket`).
- Ocultar o no listar las demás bases de datos en este formulario para mantener una interfaz limpia, focalizada y simple.
- Si se requiere cambiar de base de datos o administrar motores/buckets, remitir a la vista de administración de base de datos (`/database`).

### 1. Eliminar el botón `+ Nuevo Bucket`
- Remover el botón **+ Nuevo Bucket** de la vista `/explorer`.
- La creación, edición y eliminación de Buckets se centraliza en el administrador de la base de datos (`/database`), evitando duplicar flujos de alta de Buckets en `/explorer`.

### 2. Diálogo modal de Estructura del Bucket en `/explorer`
Cuando el usuario seleccione un **Bucket** en el árbol (`Tree`) y haga clic en **Estructura** dentro de la sección **📐 Estructura del Bucket '[nombre-bucket]' [[nombre-base-de-datos]]**:
1. **Visualización como diálogo sobre la página actual:**
   - Mostrar la estructura en un diálogo modal superpuesto sobre `/explorer` (sin navegar a otra ruta ni perder el contexto del árbol o de los registros consultados).
   - Permitir cerrar el diálogo de forma clara (botón de cierre / `Esc` / clic fuera si aplica según el patrón de `JettraFlux`).
2. **Presentación en tabla (`DataTable`):**
   - Renderizar los campos de la estructura del Bucket como una **DataTable** legible para el usuario (con columnas como `Nombre`, `Tipo`, `Reglas` / `Rules` y `Descripción`, según los metadatos disponibles del Bucket).
   - Si el Bucket no tiene estructura definida (`NONE` / esquema libre), mostrar un mensaje claro en el diálogo indicando que el Bucket acepta registros sin estructura fija.
3. **Remoción de acciones no deseadas en este diálogo:**
   - **No incluir** los botones **VER JSON**, **Editar Estructura** ni **Eliminar Estructura** dentro de este diálogo de consulta en `/explorer`.
   - Este diálogo en `/explorer` es exclusivamente de **consulta visual de la estructura**; la edición o eliminación de estructura y el JSON se mantienen fuera de este modal.
