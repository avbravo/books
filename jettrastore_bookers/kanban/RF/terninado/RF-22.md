# RF-22: Anotación `@RestRepository` para generación en tiempo de compilación de recursos REST y seguridad en `JettraRest`

## Contexto
En el proyecto **JettraRest** (desarrollado en **Java 25+** sobre **Ubuntu 26.04**, integrado con el ecosistema Jettra como **JettraAnnotation** y **JettraJWT**, y validado con **JettraTest**), actualmente los endpoints REST asociados a repositorios se exponen de forma manual, lo que duplica código y dificulta mantener reglas consistentes de rutas, parámetros, serialización y seguridad.

## Objetivo
Implementar una nueva anotación **`@RestRepository`** en **JettraRest** que, a partir de una interfaz anotada con `@Repository` y `@RestRepository`, genere en **tiempo de compilación** (`Annotation Processor` / `javax.annotation.processing.Processor`) la clase de recurso REST correspondiente (por ejemplo, `ProductRest` a partir de `ProductRepository`), exponiendo los endpoints asociados a cada método definido e integrando la configuración de seguridad.

## Ejemplo de referencia
```java
@Repository
@RestRepository
public interface ProductRepository {
    public Persona findById(String id);
}
