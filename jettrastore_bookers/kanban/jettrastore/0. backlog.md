=======jettrastoreengine===============

Al compilar jettrastoreengine con mvn clean verify revisar que se crea el directorio jettra/data
y las bases de datos samples_ambiental_db, samples_hospital_db, test_memory_engine_db, test_meter_db,
test_multiuser_db. 
Debe eliminar estas bases de datos al finalizar las pruebas.
Verifica que los proyectos JettraStore o JettraStoreShell o JettraStoreExplorer si las llegan a crear
en el proceso de testing eliminen estas bases de datos de prueba.
