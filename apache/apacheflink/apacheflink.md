## Description
This plugin adds some additional features to Apache Netbeans Markdown Editor.
- Preview
- Split Window
- Suggestion
- Export to DOCX, PDF and HTML

# Descargas
[Descargar](https://nightlies.apache.org/flink/flink-docs-stable/docs/try-flink/local_installation/)

Pasos
1. Descargar archivo .tgz

2. Descomprimir archivo
```shell

  tar -xzf flink-*.tgz

```

3. Ejecutar

```shell
./bin/start-cluster.sh

```
