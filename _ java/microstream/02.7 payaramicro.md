 ## Almacenamiento
 ---------------------------------
En el archivo microprofile-config.properties
se especifica la ruta de almacenamiento
#microstream
one.microstream.storage.directory=target/data
one.microstream.channel.count=4


Debemos crear la carpeta /data dentro de target

En la carpeta build crear el directorio /target/data

### Si nos movemos a otro disco u unidad
copiar la carpeta data al lugar deseado
