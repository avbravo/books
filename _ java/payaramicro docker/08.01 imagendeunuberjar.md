# 08.01 Crear imagen a partir de un UberJar

Mostraremos como crear imagenes de docker que se ejecutan localmente y
como subirla a dockerhub.


# --------------------------------
# Clonar proyecto
# --------------------------------
```
https://github.com/avbravo/microprofilerestclientserver
```
Revisar el archivo Dockerfile


# --------------------------------
#  Dockenizar un UberJar
# -------------------------------

Usaremos el jdk zulu

Crear el Dockfile
```
FROM azul/zulu-openjdk-alpine:11

ENV APP_LOCATION target/test-app.jar
ENV APP_NAME application.jar

ADD $APP_LOCATION $APP_NAME
RUN chmod +x $APP_NAME

EXPOSE 8080

ENTRYPOINT java -jar $APP_NAME
```

Build de la imagen
```
docker build -t payara-uber-jar .
```

Ejecutar
```
docker run -d -p 8080:8080 --name uber-jar payara-uber-jar
```
# -------------------------------
## Para conexiones a MongoDB
# -------------------------------
En el proyecto usamos una configuracion a monogdb
esta en el archivo microprofile-config.properties

Si usa MongoDB indique el Ip del servidor, si va a utlizar localhost, debe crear primero una red

indique el ip si usa , si usa otro contenedor debe crear una red

Crear una red

```
 docker network create mynetwork

```

Ejecutar en una misma red

```
docker run -d -p 8080:8080 --name uber-jar payara-uber-jar --network mynetwork
```
