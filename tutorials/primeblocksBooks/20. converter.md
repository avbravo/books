## Embebidos sin llave primaria

por Ejemplo Profile:

- Asignar un @Ignore que indica que sera ignorado por el framework

```java
@DocumentEmbeddable
public class Profile {

    @Ignore
    private Long id;
    @Referenced(from = "applicative", localField = "idapplicative")
    private Applicative applicative;
    @Referenced(from = "role", localField = "idrole")
    private Role role;
    @Referenced(from = "departament", localField = "iddepartament")
    private Departament departament;

    @Column
    private Boolean active;
}

```

- En LoginFaces procesarlo y agregarle un valor a id mediante un contador, de esta manera servira como atributo primario aunque no se almacene en la base de datos

```java
/**
* Recorrer el profile y asignarle un valor secuencial a id 
*/
Long counter = 0L;
for (Role r : appconfigurationLogged.getRole()) {

    if (r.getActive()) {

        for (Profile p : userLogged.getProfile()) {

            if (p.getApplicative().getIdapplicative().equals(appconfigurationLogged.getApplicative().getIdapplicative())) {

                if (p.getRole().getIdrole().equals(r.getIdrole())) {
                    counter++;
                    p.setId(counter);
                    profileListLogged.add(p);
                }
            }
        }
    }
}

```

- Crear el converter
```xml
  <p:selectOneListbox id="profile" value="#{loginFaces.profileLogged}" 

                    >

    <f:selectItems value="#{loginFaces.profileListLogged}" 
                   var="var"

    <p:column>

        <i class="pi pi-check"></i>
    </p:column>


</p:selectOneListbox>


```

Como puede observar el automaticamente llamara al converter definido.
