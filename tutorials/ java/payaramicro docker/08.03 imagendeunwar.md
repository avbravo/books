# ----------------------------
# Imagen desde un war
# ----------------------------
Dockerfile
```
FROM payara/micro

COPY target/microprofilerestclientserver.war $DEPLOY_DIR

```

Generar el build
```
docker build -t myapplication .
```

Ejecutarlo
```
docker run -d -p 8080:8080 --name myapplication myapplication
```

# Archivo Dockerfile
```
FROM payara/micro
COPY target/microprofilerestclientserver.war /opt/payara/deployments/microprofilerestclientserver.war
```

## ------------------------------------
#  Crear imagen
## ------------------------------------


## clean package
```
mvn clean package
```
## Crear imagen

```
 docker build -t mi-croprofilerestclientserver . 
```

# Create a container
```
docker run -itd --name microprofilerestclientserver --publish 80:8080 microprofilerestclientserver
```
# ver el container
docker ps -a

# ----------- detener la imagen primero
 docker stop id-imagen

# Delete custom image
```
docker rmi microprofilerestclientserver
```
