# 07.05 encriptacion
Uno de los algoritmos mas seguros para encriptar en blake3 
- Rapido
- Seguro
- No permite volver a conocer la clave
## Referencias
https://github.com/rctcwyvrn/blake3
https://jarcasting.com/artifacts/io.github.rctcwyvrn/blake3/


## Clonar el proyecto

https://github.com/avbravo/criptografia

## Dependencias
```
<dependency>
   <groupId>io.github.rctcwyvrn</groupId>
   <artifactId>blake3</artifactId>
   <version>1.3</version>
</dependency>
```

## Uso
```
// Hashing bytes
        Blake3 hasher = Blake3.newInstance();
        hasher.update("This is a string".getBytes());
        String hexhash = hasher.hexdigest();
```      
        


## en jmoordb
a partir del release -2.5.4
implementa encriptación mediante blake3
```  
JmoordbBlake3.encripter(String textToEncripter, Integer... numberOfBytes)


String encriptado = JmoordbBlake3.encripter("Hola mundo"); //256

String encriptado256 = JmoordbBlake3.encripter("Hola mundo",256); //256 bytes

String encriptado128 = JmoordbBlake3.encripter("Hola mundo",128); //128 bytes
```
