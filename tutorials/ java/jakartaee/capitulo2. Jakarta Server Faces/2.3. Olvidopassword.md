# 2.3 Olvido Password

Para manejar cuando un usuario olvidó la contraseña.
Se maneja mediante formularios donde el usuario indica el pasword y se envia credenciales.
Formularios:

- login.xhtml → (olvido password)
-  password.xhtml (ingresa email, se genera un registro en la colección de token y se se envía un url al usuario con el formato token-transaccionid- userid) → desde el correo el usuario da click en el link y llega a
-  passwordchange.xhtml.


##Uso
Al correo del usuario se le envía un enlace como el siguiente.
```
http://localhost:8080/templatefaces/passwordchange.xhtml?token=3455-123-12
```

##Implementación:

passwordchange.xhtml (recibe un url con la estructura token-transaccionid-userid), el formulario se invoca mediante el link que el usuario da click desde su correo, Por lo tanto necesitamos obtener el key enviado en el url como parámetro, descomponerlo y procesar si es un key válido en ese caso se muestra las componentes password para que el usuario pueda cambiarlas.
