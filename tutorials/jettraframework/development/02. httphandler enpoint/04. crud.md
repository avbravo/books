Vamos a crear un CRUD (Create, Read, Update, Delete) básico para una clase `Persona` utilizando `HttpHandler` en Java. Este ejemplo mostrará cómo manejar las operaciones CRUD a través de diferentes endpoints HTTP.

### 1. Estructura del proyecto

Primero, definiremos la clase `Persona` y luego crearemos un servidor HTTP con endpoints para realizar las operaciones CRUD.

### 2. Clase `Persona`

La clase `Persona` tendrá los siguientes atributos: `id`, `nombre`, y `edad`.

```java
public class Persona {
    private int id;
    private String nombre;
    private int edad;

    // Constructor
    public Persona(int id, String nombre, int edad) {
        this.id = id;
        this.nombre = nombre;
        this.edad = edad;
    }

    // Getters y Setters
    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getNombre() {
        return nombre;
    }

    public void setNombre(String nombre) {
        this.nombre = nombre;
    }

    public int getEdad() {
        return edad;
    }

    public void setEdad(int edad) {
        this.edad = edad;
    }

    @Override
    public String toString() {
        return "Persona{id=" + id + ", nombre='" + nombre + "', edad=" + edad + "}";
    }
}
```

### 3. Servidor HTTP con CRUD

Ahora, implementaremos el servidor HTTP con endpoints para realizar las operaciones CRUD sobre la clase `Persona`. Usaremos una lista en memoria para almacenar las personas.

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.io.InputStream;
import java.net.InetSocketAddress;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;

public class PersonaCRUD {

    // Lista en memoria para almacenar las personas
    private static List<Persona> personas = new ArrayList<>();
    private static int idCounter = 1;

    public static void main(String[] args) throws IOException {
        // Crear una instancia del servidor HTTP
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);

        // Endpoints CRUD
        server.createContext("/personas", new PersonaHandler());
        server.createContext("/personas/", new PersonaByIdHandler());

        // Iniciar el servidor
        server.setExecutor(null); // Usa el executor por defecto
        server.start();
        System.out.println("Servidor iniciado en http://localhost:8080");
    }

    // Handler para manejar todas las personas (GET, POST)
    static class PersonaHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            String method = exchange.getRequestMethod();

            // GET: Obtener todas las personas
            if ("GET".equals(method)) {
                String response = personas.toString();
                exchange.sendResponseHeaders(200, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            }
            // POST: Crear una nueva persona
            else if ("POST".equals(method)) {
                InputStream requestBody = exchange.getRequestBody();
                String body = new String(requestBody.readAllBytes());

                // Parsear el cuerpo de la solicitud (nombre,edad)
                String[] parts = body.split(",");
                String nombre = parts[0];
                int edad = Integer.parseInt(parts[1]);

                Persona nuevaPersona = new Persona(idCounter++, nombre, edad);
                personas.add(nuevaPersona);

                String response = "Persona creada: " + nuevaPersona;
                exchange.sendResponseHeaders(201, response.getBytes().length);
                OutputStream os = exchange.getResponseBody();
                os.write(response.getBytes());
                os.close();
            } else {
                // Método no permitido
                exchange.sendResponseHeaders(405, -1); // 405 Method Not Allowed
            }
        }
    }

    // Handler para manejar una persona específica por ID (GET, PUT, DELETE)
    static class PersonaByIdHandler implements HttpHandler {
        @Override
        public void handle(HttpExchange exchange) throws IOException {
            String method = exchange.getRequestMethod();
            String path = exchange.getRequestURI().getPath();
            int id = Integer.parseInt(path.substring(path.lastIndexOf("/") + 1));

            Optional<Persona> personaOpt = personas.stream()
                    .filter(p -> p.getId() == id)
                    .findFirst();

            // GET: Obtener una persona por ID
            if ("GET".equals(method)) {
                if (personaOpt.isPresent()) {
                    String response = personaOpt.get().toString();
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // 404 Not Found
                }
            }
            // PUT: Actualizar una persona por ID
            else if ("PUT".equals(method)) {
                if (personaOpt.isPresent()) {
                    InputStream requestBody = exchange.getRequestBody();
                    String body = new String(requestBody.readAllBytes());

                    // Parsear el cuerpo de la solicitud (nombre,edad)
                    String[] parts = body.split(",");
                    String nombre = parts[0];
                    int edad = Integer.parseInt(parts[1]);

                    Persona persona = personaOpt.get();
                    persona.setNombre(nombre);
                    persona.setEdad(edad);

                    String response = "Persona actualizada: " + persona;
                    exchange.sendResponseHeaders(200, response.getBytes().length);
                    OutputStream os = exchange.getResponseBody();
                    os.write(response.getBytes());
                    os.close();
                } else {
                    exchange.sendResponseHeaders(404, -1); // 404 Not Found
                }
            }
            // DELETE: Eliminar una persona por ID
            else if ("DELETE".equals(method)) {
                if (personaOpt.isPresent()) {
                    personas.remove(personaOpt.get());
                    exchange.sendResponseHeaders(204, -1); // 204 No Content
                } else {
                    exchange.sendResponseHeaders(404, -1); // 404 Not Found
                }
            } else {
                // Método no permitido
                exchange.sendResponseHeaders(405, -1); // 405 Method Not Allowed
            }
        }
    }
}
```

### 4. Explicación del código

#### **Clase `Persona`**
- La clase `Persona` tiene tres atributos: `id`, `nombre`, y `edad`.
- También incluye getters, setters y un método `toString()` para representar la persona como una cadena.

#### **Servidor HTTP**
- **`/personas`**: Este endpoint maneja las operaciones para obtener todas las personas (`GET`) y crear una nueva persona (`POST`).
  
  - **GET**: Devuelve una lista de todas las personas.
  - **POST**: Crea una nueva persona. El cuerpo de la solicitud debe ser una cadena en el formato `nombre,edad` (por ejemplo, `"Juan,30"`).

- **`/personas/{id}`**: Este endpoint maneja las operaciones para obtener, actualizar o eliminar una persona específica por su `id`.
  
  - **GET**: Devuelve la persona con el `id` especificado.
  - **PUT**: Actualiza la persona con el `id` especificado. El cuerpo de la solicitud debe ser una cadena en el formato `nombre,edad`.
  - **DELETE**: Elimina la persona con el `id` especificado.

#### **Manejo de errores**
- Si se intenta acceder a una persona que no existe, se devuelve un código de estado `404 Not Found`.
- Si se utiliza un método HTTP no permitido, se devuelve un código de estado `405 Method Not Allowed`.

### 5. Ejecutar el servidor

Para ejecutar el servidor, compila y ejecuta el archivo Java:

```bash
javac PersonaCRUD.java
java PersonaCRUD
```

El servidor estará disponible en `http://localhost:8080`.

### 7. Consideraciones adicionales

- **Validación**: En este ejemplo, no se realiza validación exhaustiva de los datos de entrada. En un entorno de producción, deberías validar los datos recibidos en las solicitudes POST y PUT.
  
- **Persistencia**: Este ejemplo almacena los datos en memoria, lo que significa que los datos se perderán cuando el servidor se detenga. Para una aplicación real, deberías usar una base de datos para persistir los datos.

- **Seguridad**: Este servidor es muy básico y no tiene características de seguridad avanzadas. Si planeas exponerlo a Internet, considera agregar autenticación, cifrado (HTTPS) y otras medidas de seguridad.

Sin embargo, para aplicaciones más grandes y complejas, es recomendable usar frameworks como Spring Boot o Jakarta EE.
