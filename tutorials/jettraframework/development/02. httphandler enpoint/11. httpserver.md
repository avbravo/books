Crear un endpoint utilizando la **Java HTTP Server API** es una forma sencilla y eficiente de construir un servidor web básico sin necesidad de frameworks adicionales. Esta API está disponible desde Java 6 y es parte del paquete `com.sun.net.httpserver`. A continuación, te explico paso a paso cómo crear un endpoint básico.

---

### **Paso 1: Importar las clases necesarias**
Primero, necesitas importar las clases que proporciona la API para manejar el servidor HTTP.

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.net.InetSocketAddress;
```

---

### **Paso 2: Crear el servidor HTTP**
El siguiente paso es crear una instancia del servidor HTTP y configurar el puerto en el que escuchará las solicitudes.

```java
public class SimpleHttpServer {
    public static void main(String[] args) throws IOException {
        // Crear una instancia del servidor HTTP
        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);

        // Crear un contexto para el endpoint "/hello"
        server.createContext("/hello", new HelloHandler());

        // Iniciar el servidor
        server.setExecutor(null); // Usar el executor por defecto
        server.start();

        System.out.println("Servidor iniciado en http://localhost:8080/hello");
    }
}
```

En este ejemplo:
- El servidor escucha en el puerto `8080`.
- Se define un contexto (`/hello`) que será el endpoint al que se pueden enviar solicitudes.
- `setExecutor(null)` indica que el servidor usará un pool de hilos predeterminado para manejar las solicitudes.

---

### **Paso 3: Implementar el manejador (Handler)**
El manejador es responsable de procesar las solicitudes entrantes y generar respuestas. Para esto, implementas la interfaz `HttpHandler`.

```java
static class HelloHandler implements HttpHandler {
    @Override
    public void handle(HttpExchange exchange) throws IOException {
        // Definir la respuesta
        String response = "¡Hola, mundo!";

        // Configurar los encabezados de la respuesta
        exchange.sendResponseHeaders(200, response.getBytes().length);

        // Escribir la respuesta en el cuerpo de la solicitud
        OutputStream os = exchange.getResponseBody();
        os.write(response.getBytes());
        os.close();
    }
}
```

En este manejador:
- Se define una respuesta simple: `"¡Hola, mundo!"`.
- `sendResponseHeaders(200, length)` envía el código de estado HTTP (`200 OK`) y la longitud de la respuesta.
- La respuesta se escribe en el cuerpo de la solicitud mediante `OutputStream`.

---

### **Paso 4: Probar el servidor**
Una vez que ejecutas el programa, puedes probar el endpoint utilizando un navegador o una herramienta como `curl` o Postman.

1. Abre un navegador y navega a:  
   ```
   http://localhost:8080/hello
   ```

2. O usa `curl` desde la terminal:
   ```bash
   curl http://localhost:8080/hello
   ```

Deberías ver la respuesta:  
```
¡Hola, mundo!
```

---

### **Explicación del flujo completo**
1. El servidor se inicia y escucha en el puerto `8080`.
2. Cuando una solicitud llega al endpoint `/hello`, el servidor delega el manejo de la solicitud al `HelloHandler`.
3. El `HelloHandler` genera una respuesta con el mensaje `"¡Hola, mundo!"` y la envía al cliente.
4. El cliente recibe la respuesta y la muestra.

---

### **Extensión: Manejo de diferentes métodos HTTP**
Si deseas manejar diferentes métodos HTTP (como `GET`, `POST`, etc.), puedes verificar el método en el manejador:

```java
@Override
public void handle(HttpExchange exchange) throws IOException {
    if ("GET".equals(exchange.getRequestMethod())) {
        String response = "Respuesta para GET";
        exchange.sendResponseHeaders(200, response.getBytes().length);
        OutputStream os = exchange.getResponseBody();
        os.write(response.getBytes());
        os.close();
    } else if ("POST".equals(exchange.getRequestMethod())) {
        String response = "Respuesta para POST";
        exchange.sendResponseHeaders(200, response.getBytes().length);
        OutputStream os = exchange.getResponseBody();
        os.write(response.getBytes());
        os.close();
    } else {
        String response = "Método no permitido";
        exchange.sendResponseHeaders(405, response.getBytes().length);
        OutputStream os = exchange.getResponseBody();
        os.write(response.getBytes());
        os.close();
    }
}
```

### **Conclusión**
La **Java HTTP Server API** es una herramienta ligera y fácil de usar para crear servidores HTTP básicos. Es ideal para prototipos o aplicaciones simples donde no se requiere un framework complejo. Sin embargo, para proyectos más grandes o con requisitos avanzados, podrías considerar frameworks como **Spring Boot** o **Micronaut**.

**Código completo final:**

```java
import com.sun.net.httpserver.HttpServer;
import com.sun.net.httpserver.HttpHandler;
import com.sun.net.httpserver.HttpExchange;

```
