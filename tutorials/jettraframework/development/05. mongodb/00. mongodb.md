### 4. Repositorios (`PersonaRepository` y `PaisRepository`)
Estas clases implementan el patrón repositorio para interactuar con MongoDB.

#### `PersonaRepository.java`
```java
package com.example.repository;

import com.example.model.Persona;
import com.mongodb.client.MongoClient;
import com.mongodb.client.MongoCollection;
import org.bson.Document;

import static com.mongodb.client.model.Filters.eq;

public class PersonaRepository {
    private final MongoCollection<Persona> collection;

    public PersonaRepository(MongoClient mongoClient) {
        this.collection = mongoClient.getDatabase("testdb").getCollection("personas", Persona.class);
    }

    public void save(Persona persona) {
        collection.insertOne(persona);
    }

    public Persona findById(String id) {
        return collection.find(eq("_id", new org.bson.types.ObjectId(id))).first();
    }
}
```

### 5. Producer para MongoDB (`MongoProducer.java`)
Esta clase produce una instancia de `MongoClient`.

```java
package com.example.config;

import com.mongodb.client.MongoClient;
import com.mongodb.client.MongoClients;

public class MongoProducer {
```

### 7. Manejador HTTP (`HttpServerHandler.java`)
Este manejador procesa las solicitudes HTTP.

```java
package com.example.handler;

import com.example.service.PersonaService;
import com.example.service.PaisService;

import com.sun.net.httpserver.HttpExchange;
import com.sun.net.httpserver.HttpHandler;

import java.io.IOException;
import java.io.OutputStream;

public class HttpServerHandler implements HttpHandler {

    private final PersonaService personaService;
    private final PaisService paisService;

    public HttpServerHandler(PersonaService personaService, PaisService paisService) {
        this.personaService = personaService;
        this.paisService = paisService;
    }

    @Override
    public void handle(HttpExchange exchange) throws IOException {
        String response = "Hello, World!";
        exchange.sendResponseHeaders(200, response.getBytes().length);
        OutputStream os = exchange.getResponseBody();
        os.write(response.getBytes());
        os.close();
    }
}
```

### 8. Ejecución del Servidor HTTP
Finalmente, puedes iniciar un servidor HTTP básico usando `com.sun.net.httpserver.HttpServer`.

```java
import com.example.config.MongoProducer;
import com.example.handler.HttpServerHandler;
import com.example.repository.PersonaRepository;
import com.example.repository.PaisRepository;
import com.example.service.PersonaService;
import com.example.service.PaisService;
import com.mongodb.client.MongoClient;

import com.sun.net.httpserver.HttpServer;

import java.io.IOException;
import java.net.InetSocketAddress;

public class Main {
    public static void main(String[] args) throws IOException {
        // Configuración manual de dependencias
        MongoClient mongoClient = MongoProducer.createMongoClient();
        PersonaRepository personaRepository = new PersonaRepository(mongoClient);
        PaisRepository paisRepository = new PaisRepository(mongoClient);

        PersonaService personaService = new PersonaService(personaRepository);
        PaisService paisService = new PaisService(paisRepository);

        HttpServer server = HttpServer.create(new InetSocketAddress(8080), 0);
        server.createContext("/", new HttpServerHandler(personaService, paisService));
        server.setExecutor(null); // Usa el executor por defecto
        server.start();

        System.out.println("Servidor iniciado en http://localhost:8080/");
    }
}
```
