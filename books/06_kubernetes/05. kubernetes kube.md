### **¿Qué es Kubernetes?**

Kubernetes (a menudo abreviado como **k8s**) es un sistema de orquestación de contenedores de código abierto que permite automatizar la implementación, el escalado y la gestión de aplicaciones en contenedores. Fue desarrollado originalmente por Google y ahora es mantenido por la **Cloud Native Computing Foundation (CNCF)**.

#### **Conceptos clave de Kubernetes**
1. **Contenedores**: Kubernetes trabaja con contenedores (generalmente Docker), que son unidades ligeras y portátiles de software que incluyen todo lo necesario para ejecutar una aplicación.
2. **Cluster**: Un conjunto de máquinas (físicas o virtuales) donde se ejecutan las aplicaciones en contenedores. Un clúster consta de:
   - **Nodos maestros (Master Nodes)**: Gestiona el clúster y coordina las tareas.
   - **Nodos trabajadores (Worker Nodes)**: Ejecutan las aplicaciones en contenedores.
3. **Pods**: La unidad más pequeña de Kubernetes. Un pod puede contener uno o más contenedores que comparten recursos.
4. **Servicios**: Permiten la comunicación entre pods y exponen aplicaciones al exterior.
5. **Controladores**: Automatizan tareas como el mantenimiento del número deseado de réplicas de un pod (Deployment, ReplicaSet, etc.).

### **Instalación de Kubernetes en Ubuntu**

Para instalar Kubernetes en tu computadora con Ubuntu, puedes configurar un clúster local utilizando herramientas como **Minikube** o **kubeadm**. A continuación, te explico cómo hacerlo con ambas opciones.

---

#### **Opción 1: Usando Minikube**
Minikube es una herramienta ligera que permite ejecutar un clúster de Kubernetes de un solo nodo en tu máquina local. Es ideal para desarrollo y pruebas.

##### **Pasos para instalar Minikube en Ubuntu**
1. **Actualizar el sistema**
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

2. **Instalar Docker (como runtime de contenedores)**
   ```bash
   sudo apt install docker.io -y
   sudo systemctl enable docker
   sudo systemctl start docker
   ```

3. **Instalar kubectl (la CLI de Kubernetes)**
   ```bash
   curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
   chmod +x kubectl
   sudo mv kubectl /usr/local/bin/
   ```

4. **Instalar Minikube**
   ```bash
   curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
   sudo install minikube-linux-amd64 /usr/local/bin/minikube
   ```

5. **Iniciar Minikube**
   ```bash
   minikube start --driver=docker
   ```

6. **Verificar la instalación**
   ```bash
   kubectl get nodes
   ```
   Esto debería mostrar un nodo activo.

7. **Acceder al dashboard de Kubernetes (opcional)**
   ```bash
   minikube dashboard
   ```

---

#### **Opción 2: Usando kubeadm**
`kubeadm` es una herramienta oficial de Kubernetes para crear un clúster multi-nodo. Es más compleja que Minikube, pero es adecuada si quieres simular un entorno de producción.

##### **Pasos para instalar Kubernetes con kubeadm en Ubuntu**
1. **Actualizar el sistema**
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

2. **Deshabilitar el intercambio (swap)**
   Kubernetes no funciona bien con swap habilitado.
   ```bash
   sudo swapoff -a
   ```

3. **Instalar Docker**
   ```bash
   sudo apt install docker.io -y
   sudo systemctl enable docker
   sudo systemctl start docker
   ```

4. **Agregar el repositorio de Kubernetes**
   ```bash
   sudo apt install -y apt-transport-https ca-certificates curl
   curl -fsSL https://pkgs.k8s.io/core:/stable:/v1.28/deb/Release.key | sudo gpg --dearmor -o /etc/apt/trusted.gpg.d/kubernetes.gpg
   echo 'deb [signed-by=/etc/apt/trusted.gpg.d/kubernetes.gpg] https://pkgs.k8s.io/core:/stable:/v1.28/deb/ /' | sudo tee /etc/apt/sources.list.d/kubernetes.list
   sudo apt update
   ```

5. **Instalar kubeadm, kubelet y kubectl**
   ```bash
   sudo apt install -y kubeadm kubelet kubectl
   sudo apt-mark hold kubeadm kubelet kubectl
   ```

6. **Inicializar el clúster**
   ```bash
   sudo kubeadm init --pod-network-cidr=10.244.0.0/16
   ```

7. **Configurar kubectl**
   Después de inicializar el clúster, ejecuta los siguientes comandos como usuario normal:
   ```bash
   mkdir -p $HOME/.kube
   sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
   sudo chown $(id -u):$(id -g) $HOME/.kube/config
   ```

8. **Instalar un plugin de red (Flannel)**
   ```bash
   kubectl apply -f https://raw.githubusercontent.com/coreos/flannel/master/Documentation/kube-flannel.yml
   ```

9. **Verificar el estado del clúster**
   ```bash
   kubectl get nodes
   ```

10. **Unir nodos adicionales (opcional)**
    Si tienes más máquinas, puedes unirlas al clúster usando el comando proporcionado por `kubeadm init`.

### **Configuración básica de Kubernetes**

Una vez instalado Kubernetes, puedes comenzar a desplegar aplicaciones. Aquí hay algunos comandos básicos:

1. **Desplegar una aplicación**
   ```bash
   kubectl create deployment hello-world --image=nginx
   ```

2. **Exponer la aplicación**
   ```bash
   kubectl expose deployment hello-world --type=NodePort --port=80
   ```

3. **Ver los servicios**
   ```bash
   kubectl get services
   ```

4. **Eliminar recursos**
   ```bash
   kubectl delete deployment hello-world
   kubectl delete service hello-world
   ```

### **Conclusión**

- **Minikube** es ideal para desarrollo y pruebas locales, ya que es fácil de configurar y usar.
- **kubeadm** es más adecuado para simular entornos de producción, pero requiere más configuración.

Ambas opciones te permitirán aprender y experimentar con Kubernetes en tu computadora con Ubuntu. Si tienes dudas o necesitas ayuda adicional, ¡no dudes en preguntar! 😊
