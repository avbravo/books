# 08. knob

Componente para generar knob

##  Definición de componente:

* data-value: valor del componente entre **0 y 100**

* label: Valor de la etiqueta a mostrar fuera del knob
* counter: Valor del contador a mostrar fuerda del knob

* arrowtype: Tipo de flecha **arrowtype: right-up, left-down**

* circle-progress-type: Tipo de circulo. **circle-progress-type = circle-progress-primary, circle-progress-info**

**Composite**

```html
    <composite:interface >
            <!--design = simple, profile-->
        <composite:attribute name="data-value" default="100"/> 
        <composite:attribute name="label" default=""/> 
        <composite:attribute name="counter" default=""/> 
        <!--typerow: right-up, left-down-->
        <composite:attribute name="arrowtype" default="right-up"/> 
        <!--circle-progress-type = circle-progress-primary, circle-progress-info, -->
        <composite:attribute name="circle-progress-type" default="circle-progress-primary"/>
    </composite:interface>

```

**Implementation**

```
 <composite:implementation>

        <div class="card-body">
            <div class="progress-widget">                                        
                <div id="circle-progress-01" class="text-center circle-progress-01 circle-progress #{cc.attrs.circle-progress-type}" data-min-value="0" data-max-value="100" data-value="#{cc.attrs.data-value}" data-type="percent">          
                    <c:if test="${cc.attrs.arrowtype eq 'right-up'}">
                        <svg class="card-slie-arrow icon-24" width="24"  viewBox="0 0 24 24">
                            <path fill="currentColor" d="M5,17.59L15.59,7H9V5H19V15H17V8.41L6.41,19L5,17.59Z" />
                        </svg>
                    </c:if>
                    <c:if test="${cc.attrs.arrowtype eq 'left-down'}">
                        <svg class="card-slie-arrow icon-24" width="24" viewBox="0 0 24 24">
                            <path fill="currentColor" d="M19,6.41L17.59,5L7,15.59V9H5V19H15V17H8.41L19,6.41Z" />
                        </svg>
                    </c:if>
                </div>
                <div class="progress-detail">
                    <p  class="mb-2">#{cc.attrs.label}</p>
                    <h4 class="counter">#{cc.attrs.counter}</h4>
                </div>
            </div>
        </div>
    </composite:implementation>

```


**Descripción:**


Se usa para dibujar un knob.
