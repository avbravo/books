## 04.1 NavHeader

Es la barra de encabezado que se muestra en cada formulario

* Recuerde que puede indicar imagenes locales, de jmoordbcoreui o iconos de primefaces.
  

```java
 public NavHeader createNavHeader() {
        NavHeader navHeader = new NavHeader();
        try {
            navHeader = new NavHeader.Builder()
                    .title("Hola Devs")
                    .message("Tenemos la misión de ayudar a desarrolladores como usted a construir proyectos exitosos GRATIS.")
                    .hrefInfo(new HrefInfo.Builder().href("").text("Anuncio").minText("a").build())
                    .imageInfo(new ImageInfo.Builder().library("jmoordbcoreui").name("images/svg/botones/anuncio.svg").imageContextRoot(FacesUtil.contextPath()).build())
                    .imageInfos(Arrays.asList(
                            new ImageInfo.Builder().library("jmoordbcoreui").name("images/dashboard/top-header.png").imageContextRoot(FacesUtil.contextPath()).build(),
                            new ImageInfo.Builder().library("jmoordbcoreui").name("images/dashboard/top-header1.png").imageContextRoot(FacesUtil.contextPath()).build(),
                            new ImageInfo.Builder().library("jmoordbcoreui").name("images/dashboard/top-header2.png").imageContextRoot(FacesUtil.contextPath()).build(),
                            new ImageInfo.Builder().library("jmoordbcoreui").name("images/dashboard/top-header4.png").imageContextRoot(FacesUtil.contextPath()).build(),
                            new ImageInfo.Builder().library("jmoordbcoreui").name("images/dashboard/top-header5.png").imageContextRoot(FacesUtil.contextPath()).build()
                    )
                    )
                    .build();
        } catch (Exception e) {
           FacesUtil.showError(FacesUtil.nameOfClassAndMethod() + " "+e.getLocalizedMessage());
        }
        return navHeader;
    }
```
