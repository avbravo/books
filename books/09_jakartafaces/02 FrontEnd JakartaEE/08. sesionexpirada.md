# Control de Sesión Expirada en Jakarta Faces (JSF)

Para manejar la expiración de sesión en Jakarta Faces (antes JavaServer Faces) y redirigir a una página de mensaje, además de mostrar advertencias antes de que finalice, puedes implementar las siguientes soluciones:

## 1. Configuración básica de tiempo de sesión

Primero, configura el tiempo de sesión en tu `web.xml`:

```xml
<session-config>
    <session-timeout>30</session-timeout> <!-- Tiempo en minutos -->
</session-config>
```

## 2. Manejo de redirección al expirar la sesión

### Opción A: Usar Filter

```java
import jakarta.servlet.*;
import jakarta.servlet.http.*;
import java.io.IOException;

public class SessionExpiredFilter implements Filter {
    
    @Override
    public void doFilter(ServletRequest request, ServletResponse response, FilterChain chain) 
            throws IOException, ServletException {
        
        HttpServletRequest req = (HttpServletRequest) request;
        HttpServletResponse res = (HttpServletResponse) response;
        
        HttpSession session = req.getSession(false);
        
        if (session == null || session.getAttribute("user") == null) {
            // Sesión expirada o usuario no autenticado
            String ajaxHeader = req.getHeader("Faces-Request");
            
            if ("partial/ajax".equals(ajaxHeader)) {
                // Para peticiones AJAX
                res.setContentType("text/xml");
                res.getWriter()
                    .append("<?xml version=\"1.0\" encoding=\"UTF-8\"?>")
                    .printf("<partial-response><redirect url=\"%s\"></redirect></partial-response>", 
                            req.getContextPath() + "/session-expired.xhtml");
            } else {
                // Para peticiones normales
                res.sendRedirect(req.getContextPath() + "/session-expired.xhtml");
            }
        } else {
            chain.doFilter(request, response);
        }
    }
    
    // Implementar init y destroy si es necesario
}
```

Registra el filtro en `web.xml`:

```xml
<filter>
    <filter-name>SessionExpiredFilter</filter-name>
    <filter-class>com.tu.paquete.SessionExpiredFilter</filter-class>
</filter>
<filter-mapping>
    <filter-name>SessionExpiredFilter</filter-name>
    <url-pattern>*.xhtml</url-pattern>
</filter-mapping>
```

### Opción B: Usar PhaseListener

```java
import jakarta.faces.event.PhaseEvent;
import jakarta.faces.event.PhaseId;
import jakarta.faces.event.PhaseListener;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.faces.context.FacesContext;

public class SessionPhaseListener implements PhaseListener {

    @Override
    public void afterPhase(PhaseEvent event) {
        FacesContext context = event.getFacesContext();
        HttpServletRequest request = (HttpServletRequest) context.getExternalContext().getRequest();
        
        if (!request.getRequestURI().contains("session-expired.xhtml")) {
            HttpSession session = request.getSession(false);
            
            if (session == null || session.getAttribute("user") == null) {
                context.getExternalContext().redirect(
                    request.getContextPath() + "/session-expired.xhtml");
            }
        }
    }

    @Override
    public void beforePhase(PhaseEvent event) {}

    @Override
    public PhaseId getPhaseId() {
        return PhaseId.RESTORE_VIEW;
    }
}
```

Registra el listener en `faces-config.xml`:

```xml
<lifecycle>
    <phase-listener>com.tu.paquete.SessionPhaseListener</phase-listener>
</lifecycle>
```

## 3. Mostrar advertencia antes de que expire la sesión

Implementa un contador de inactividad con JavaScript:

```xhtml
<h:outputScript>
    var sessionTimeout = #{session.maxInactiveInterval};
    var warningTime = 120; // Mostrar advertencia 2 minutos antes
    var timer;
    
    function startSessionTimer() {
        // Convertir a milisegundos
        var timeout = (sessionTimeout - warningTime) * 1000;
        
        timer = setTimeout(function() {
            showSessionWarning();
            // Redirigir cuando expire completamente
            setTimeout(function() {
                window.location.href = '#{request.contextPath}/session-expired.xhtml';
            }, warningTime * 1000);
        }, timeout);
    }
    
    function showSessionWarning() {
        // Usar PrimeFaces dialog o implementación similar
        if (typeof PF !== 'undefined') {
            PF('sessionWarningDialog').show();
        } else {
            // Implementación básica si no usas PrimeFaces
            alert('Tu sesión expirará en ' + warningTime + ' segundos. Realiza alguna acción para mantenerla activa.');
        }
    }
    
    function resetSessionTimer() {
        clearTimeout(timer);
        startSessionTimer();
    }
    
    // Iniciar el timer cuando se cargue la página
    document.addEventListener('DOMContentLoaded', startSessionTimer);
    
    // Resetear el timer con actividad del usuario
    document.addEventListener('mousemove', resetSessionTimer);
    document.addEventListener('keypress', resetSessionTimer);
</h:outputScript>
```

Ejemplo de diálogo de advertencia (usando PrimeFaces):

```xhtml
<p:dialog widgetVar="sessionWarningDialog" modal="true" header="Sesión a punto de expirar">
    <h:panelGrid columns="1">
        <h:outputText value="Tu sesión expirará en #{sessionWarningDialog.warningTime} segundos."/>
        <h:outputText value="¿Deseas extender tu sesión?"/>
        <p:commandButton value="Continuar" oncomplete="PF('sessionWarningDialog').hide(); resetSessionTimer();"/>
    </h:panelGrid>
</p:dialog>
```

## 5. Extender la sesión con AJAX (opcional)

Puedes implementar un "ping" periódico para mantener la sesión activa:

```javascript
// En tu página principal

    // Llamada AJAX simple para mantener la sesión activa
    fetch('#{request.contextPath}/keep-alive', {
        method: 'HEAD'
    });

```

Y en tu backend:

```java
@WebServlet("/keep-alive")
public class KeepAliveServlet extends HttpServlet {
    protected void doHead(HttpServletRequest request, HttpServletResponse response) {
        // Simplemente tocar la sesión para mantenerla activa
        request.getSession(false);
    }
}
```

Esta implementación proporciona:
1. Redirección automática cuando la sesión expira
2. Advertencia visual minutos antes de la expiración
3. Posibilidad de extender la sesión
4. Página personalizada para sesión expirada

Puedes ajustar los tiempos según tus necesidades específicas.

Controlar la expiración de la sesión en una aplicación Jakarta Faces y redirigir al usuario a una página de mensaje, además de mostrar una advertencia antes de que la sesión expire, requiere combinar configuraciones del lado del servidor y del lado del cliente. A continuación, te explico cómo implementar esta funcionalidad paso a paso.

---

### 1. **Configurar el tiempo de expiración de la sesión en `web.xml`**

Primero, define el tiempo máximo de inactividad para la sesión en tu archivo `web.xml`. Este valor se configura en minutos:

```xml
<session-config>
    <session-timeout>30</session-timeout> <!-- Tiempo en minutos -->
</session-config>
```

En este ejemplo, la sesión expirará después de 30 minutos de inactividad.

---

### 2. **Redirigir a una página de mensaje cuando la sesión expire**

Cuando la sesión expira, Jakarta Faces lanza una excepción de tipo `ViewExpiredException`. Puedes manejar esta excepción configurando una página de error personalizada en `web.xml`:

```xml
<error-page>
    <exception-type>javax.faces.application.ViewExpiredException</exception-type>
    <location>/sessionExpired.xhtml</location>
</error-page>
```

Crea la página `sessionExpired.xhtml` para informar al usuario que su sesión ha expirado y proporciona un enlace para iniciar sesión nuevamente:

```html
<!DOCTYPE html>
<html xmlns="http://www.w3.org/1999/xhtml"
      xmlns:h="http://xmlns.jcp.org/jsf/html">
<h:head>
    <title>Sesión Expirada</title>
</h:head>
<h:body>
    <h1>Tu sesión ha expirado</h1>
    <p>Por favor, inicia sesión nuevamente.</p>
    <h:link value="Iniciar sesión" outcome="/login.xhtml" />
</h:body>
</html>
```

### 3. **Mostrar una advertencia antes de que expire la sesión**

Para advertir al usuario unos minutos antes de que la sesión expire, puedes usar JavaScript en el lado del cliente. El siguiente script muestra una advertencia 5 minutos antes de que la sesión expire y permite al usuario mantener la sesión activa haciendo clic en "Aceptar".

#### Implementación en JavaScript:

```javascript
// Configuración del tiempo de sesión (en milisegundos)
const sessionTimeout = 30 * 60 * 1000; // 30 minutos
const warningTime = 5 * 60 * 1000; // 5 minutos antes de expirar

let timeoutWarning;

function startSessionTimer() {
    // Iniciar el temporizador para mostrar la advertencia
    timeoutWarning = setTimeout(() => {
        alert("Tu sesión está a punto de expirar. Haz clic en Aceptar para continuar.");
    }, sessionTimeout - warningTime);

    // Redirigir al usuario cuando expire la sesión
    setTimeout(() => {
        window.location.href = "/sessionExpired.xhtml"; // Redirigir a la página de sesión expirada
    }, sessionTimeout);
}

function resetSessionTimer() {
    // Reiniciar el temporizador si el usuario interactúa con la página
    clearTimeout(timeoutWarning);
    startSessionTimer();
}

// Iniciar el temporizador cuando se cargue la página
window.onload = startSessionTimer;

// Reiniciar el temporizador cuando el usuario interactúe con la página
document.addEventListener("mousemove", resetSessionTimer);
document.addEventListener("keypress", resetSessionTimer);
```

#### Explicación del código:
1. **`sessionTimeout`**: Define el tiempo total de la sesión (30 minutos).
2. **`warningTime`**: Define cuánto tiempo antes de la expiración se mostrará la advertencia (5 minutos).
3. **`startSessionTimer`**: Inicia los temporizadores para mostrar la advertencia y redirigir al usuario.
4. **`resetSessionTimer`**: Reinicia los temporizadores cuando el usuario interactúa con la página (por ejemplo, moviendo el mouse o presionando una tecla).

---

### 4. **Mantener la sesión activa mediante una solicitud AJAX**

Si deseas permitir que el usuario mantenga la sesión activa al hacer clic en "Aceptar", puedes enviar una solicitud AJAX al servidor para extender la sesión. Por ejemplo:

```javascript
function keepSessionAlive() {
    fetch("/keepSessionAlive", { method: "POST" })
        .then(response => {
            if (response.ok) {
                alert("Tu sesión ha sido extendida.");
                resetSessionTimer(); // Reiniciar el temporizador
            } else {
                alert("No se pudo extender la sesión. Por favor, inicia sesión nuevamente.");
            }
        })
        .catch(() => {
            alert("Ocurrió un error al extender la sesión.");
        });
}
```

En el lado del servidor, crea un endpoint (`/keepSessionAlive`) que simplemente acceda a la sesión para mantenerla activa:

```java
import javax.servlet.annotation.WebServlet;
import javax.servlet.http.HttpServlet;
import javax.servlet.http.HttpServletRequest;
import javax.servlet.http.HttpServletResponse;
import javax.servlet.http.HttpSession;
import java.io.IOException;

@WebServlet("/keepSessionAlive")
public class KeepSessionAliveServlet extends HttpServlet {
    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response) throws IOException {
        HttpSession session = request.getSession(false);
        if (session != null) {
            session.getLastAccessedTime(); // Acceder a la sesión para mantenerla activa
            response.setStatus(HttpServletResponse.SC_OK);
        } else {
            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
        }
    }
}
```

### Conclusión

Con esta implementación:
1. La sesión expira después de 30 minutos de inactividad.
2. Se muestra una advertencia 5 minutos antes de la expiración.
3. El usuario puede mantener la sesión activa interactuando con la página o haciendo clic en "Aceptar".

Este enfoque combina configuraciones del lado del servidor (`web.xml`) y del lado del cliente (JavaScript) para proporcionar una experiencia de usuario fluida y segura.
