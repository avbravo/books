# 05. Microprofile Rest Client

Configuraremos el proyecto para que interactue con los microservicios.

## Edite el archivo microprofile-config.properties

* Añada información del archivo pom.xml

```
#---------------------------------------
# Informacion del archivo pom.xml
#----------------------------------------
application.name=${pom.artifactId}
application.version=${pom.version}
application.createdAt=${timestamp}
```

* Añada la información del id applicative que ingreso en la colección applicative

```
#----------------------------------------------
# Configuration of Applicative
#-----------------------------------------------
idapplicative =1

#Applicative
applicativePath=/vencotapp
applicativeURL=http://localhost:8080/vencotapp

```
