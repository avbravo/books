# 06 Menu


## Menu

* Definición de componente:

**Composite**

```html
 <composite:interface >
    <composite:attribute name="id" default=""/>
    <composite:attribute name="rendered" default=""/>
    <composite:attribute name="role" default=""/>
    <composite:attribute name="href" default="index.xhtml"/>
    <composite:attribute name="value" default="H"/>
    <composite:attribute name="mini-icon" default="Horizontal"/>
    <composite:attribute name="badgespanLabel" default=""/>
    <composite:attribute name="badgespanType" default="bg-success"/>
    <composite:attribute name="aria-current" default=""/>
    <!--typeIcon = svg, circle, primefaces-->
    <composite:attribute name="typeIcon" default="circle"/>
    <composite:attribute name="icon" default="pi pi-clock"/>
    <composite:attribute name="svgLibrary" default="jmoordbcoreui"/>
    <composite:attribute name="svgName" default="images/svg/dashboard.svg"/>
</composite:interface>

```

**Implementation**

```
 <composite:implementation>
        <li class="nav-item">
            <a class="nav-link " href="#{cc.attrs.href}" aria-current="#{cc.attrs.aria-current}">
                <i class="icon">
                    <c:if test="${cc.attrs.typeIcon eq 'circle'}">
                        <svg class="icon-10" xmlns="http://www.w3.org/2000/svg" width="10" viewBox="0 0 24 24" fill="currentColor">
                            <g>
                                <circle cx="12" cy="12" r="8" fill="currentColor"></circle>
                            </g>
                        </svg>
                    </c:if>
                    <c:if test="${cc.attrs.typeIcon eq 'svg'}">
                        <h:graphicImage library="#{cc.attrs.svgLibrary}" name="#{cc.attrs.svgName}" />
                    </c:if>

                    <c:if test="${cc.attrs.typeIcon eq 'primefaces'}">
                        <i class="#{cc.attrs.icon}"></i>  
                    </c:if>
                </i>
                <i class="sidenav-mini-icon"> #{cc.attrs.mini-icon} </i>
                <c:if test="${cc.attrs.badgespanLabel eq ''}">
                    <span class="item-name"> #{cc.attrs.value}</span>
                </c:if>
                <c:if test="${cc.attrs.badgespanLabel ne ''}">
                    <span class="item-name"> #{cc.attrs.value} <span class="badge rounded-pill #{cc.attrs.badgespanType} item-name">#{cc.attrs.badgespanLabel}</span> </span>
                </c:if>
            </a>
        </li>
    </composite:implementation>
```

**Descripción:**

Los menu son elementos que no tienen submenu y tienen un evento asociado a el.

Pueden contener un badge adicional al elemento.


Si deseamos pasar un svg y agregar un icono como el siguiente:

![](resources/06/01_menu.png)


Definición de elementos

* Dashboard
* Design System (con iconos)
* Admin
* Components


Los archivos svg estan almacenados en la libreria jmoordbcoreui paquete META-INF/resources/jmoordbcoreui.images.svg

Se accesan mediante 

```
   <h:graphicImage library="jmoordbcoreui" name="images/svg/dashboard.svg" />

```


Para utilizarlo veamos un ejemplo simple:

* Opción Dashboard con svg

Especifique **typeIcon="svg"**  y en **svgName** indique la ruta y nombre completo del archivo svg.

Si usted utiliza un archivo svg ubicado en su proyecto puede modificar **svgLibrary** e indique la libreria correspondiente.

```
<jmoordbcoreui:menu  
    value="Dashboard" 
    mini-icon="D" 
    href="index.xhtml"
    aria-current="page"
    badgespanLabel=""
    badgespanType=""
    typeIcon="svg"
    svgName="images/svg/dashboard.svg" 
/>                           

```


* Opción Dashboard con primefaces-icon

 Observe la lista de iconos de primefaces en [https://www.primefaces.org/showcase/icons.xhtml?jfwid=903e8](https://www.primefaces.org/showcase/icons.xhtml?jfwid=903e8) y utilice
 
**typeIcon="primefaces"** y el parametro **icon**, coloque el icono de la lista de primefaces.

```
<jmoordbcoreui::menu 
    value="Dashboard" 
    mini-icon="D" 
    href="index.xhtml"
    aria-current="page"
    badgespanLabel=""
    badgespanType=""
    typeIcon="primefaces"
    icon="pi pi-compass"

/>    
```


* Opción Design System con badge

Para agregar un badge  utilice **badgespanLabel** especificando la etiqueta a desplegar y **badgespanType** el tipo por ejemplo *bg-success**


```
 <jmoordbcoreui::menu
   value="Design System" 
   mini-icon="UI"
   href="https://templates.iqonic.design/hope-ui/html/dist/"
   badgespanLabel="UI"
   badgespanType="bg-success"
   typeIcon="svg"
   svgName="images/svg/desingsystem.svg"
/>             
```

## Menu Grupo

* Definición de componente:

**Composite**

```
<composite:interface >
    <composite:attribute name="collapsedLabel" default="-"/>
    <composite:attribute name="normalLabel" default=""/>
    <composite:attribute name="href" default="#"/>
    <composite:attribute name="id" default=""/>

</composite:interface>

```

**Implementation**

```
<composite:implementation>
    <li class="nav-item static-item">
        <a class="nav-link static-item disabled" href="#{cc.attrs.href}" tabindex="-1">
            <span class="default-icon">#{cc.attrs.normalLabel}</span>
            <span class="mini-icon">#{cc.attrs.collapsedLabel}</span>
        </a>
    </li>
</composite:implementation>

```


**Descripción:**

Generalmente se usa para agrupar o separar elementos creando un texto de división.

Por ejemplo: **Home, Pages, Elements**




```

<jmoordbcoreui:menuGroup value="Home" mini-icon="-"/>

<jmoordbcoreui:menuGroup value="Pages" mini-icon="-"/>

<jmoordbcoreui:menuGroup value="Elements" mini-icon="-"/> 



```

## Submenu

* Definición de componente:

**Composite**

```
<composite:interface >
    <composite:attribute name="id" default=""/>
    <composite:attribute name="href" default=""/>
    <composite:attribute name="aria-controls" default=""/>
    <composite:attribute name="rendered" default=""/>
    <composite:attribute name="role" default=""/>
    <composite:attribute name="mini-icon" default=""/>
    <composite:attribute name="value" default=""/>
      <!--typeIcon = svg, circle, primefaces-->
    <composite:attribute name="typeIcon" default=""/>
    <composite:attribute name="icon" default="pi pi-clock"/>
    <composite:attribute name="svgLibrary" default="jmoordbcoreui"/>
    <composite:attribute name="svgName" default="images/svg/dashboard.svg"/>

</composite:interface>

```

**Implementation**

```
<composite:implementation>
    <a class="nav-link" data-bs-toggle="collapse" href="#{cc.attrs.href}" role="button" aria-expanded="false" aria-controls="#{cc.attrs.aria-controls}">
        <i class="icon">
            <c:if test="${cc.attrs.typeIcon eq 'circle'}">
                <svg class="icon-10" xmlns="http://www.w3.org/2000/svg" width="10" viewBox="0 0 24 24" fill="currentColor">
                    <g>
                        <circle cx="12" cy="12" r="8" fill="currentColor"></circle>
                    </g>
                </svg>
            </c:if>
            <c:if test="${cc.attrs.typeIcon eq 'svg'}">
                <h:graphicImage library="#{cc.attrs.svgLibrary}" name="#{cc.attrs.svgName}" />
            </c:if>                
            <c:if test="${cc.attrs.typeIcon eq 'primefaces'}">
                <i class="#{cc.attrs.icon}"></i>  
            </c:if>
        </i>
        <i class="sidenav-mini-icon"> #{cc.attrs.mini-icon} </i>
        <span class="item-name">#{cc.attrs.value}</span>
        <i class="right-icon">
            <svg class="icon-18" xmlns="http://www.w3.org/2000/svg" width="18" fill="none" viewBox="0 0 24 24" stroke="currentColor">
                <path stroke-linecap="round" stroke-linejoin="round" stroke-width="2" d="M9 5l7 7-7 7" />
            </svg>
        </i>
    </a>
</composite:implementation>

```

**Descripción:**
