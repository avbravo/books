# 06 Menu


**Nota:**

Si necesita generar SVG a partir de codigos utilice. [https://www.svgviewer.dev/](https://www.svgviewer.dev/)




## Menu

Los menu son elementos que no tienen submenu y tienen un evento asociado a el.

Pueden contener un badge adicional al elemento.


Si deseamos pasar un svg y agregar un icono como el siguiente:

![](resources/06/01_menu.png)


Definición de elementos

* Dashboard
* Design System (con iconos)
* Admin
* Components


Los archivos svg estan almacenados en la libreria jmoordbcoreui paquete META-INF/resources/jmoordbcoreui.images.svg

Se accesan mediante 

```
   <h:graphicImage library="jmoordbcoreui" name="images/svg/dashboard.svg" />

```


Para utilizarlo veamos un ejemplo simple:

* Opción Dashboard con svg

Especifique **typeIcon="svg"**  y en **svgName** indique la ruta y nombre completo del archivo svg.

Si usted utiliza un archivo svg ubicado en su proyecto puede modificar **svgLibrary** e indique la libreria correspondiente.

```
<jmoordbcoreui:menu  
    normalLabel="Dashboard" 
    collapsedLabel="D" 
    href="index.xhtml"
    aria-current="page"
    badgespanLabel=""
    badgespanType=""
    typeIcon="svg"
    svgName="images/svg/dashboard.svg" 
/>                           

```


* Opción Dashboard con primefaces-icon

 Observe la lista de iconos de primefaces en [https://www.primefaces.org/showcase/icons.xhtml?jfwid=903e8](https://www.primefaces.org/showcase/icons.xhtml?jfwid=903e8) y utilice
 
**typeIcon="primefaces"** y el parametro **icon**, coloque el icono de la lista de primefaces.

```
<jmoordbcoreui::menu 
    value="Dashboard" 
    min-value="D" 
    href="index.xhtml"
    aria-current="page"
    badgespanLabel=""
    badgespanType=""
    typeIcon="primefaces"
    icon="pi pi-compass"

/>    
```


* Opción Design System con badge

Para agregar un badge  utilice **badgespanLabel** especificando la etiqueta a desplegar y **badgespanType** el tipo por ejemplo *bg-success**


```
 <jmoordbcoreui::menu
   value="Design System" 
   min-value="UI"
   href="https://templates.iqonic.design/hope-ui/html/dist/"
   badgespanLabel="UI"
   badgespanType="bg-success"
   typeIcon="svg"
   svgName="images/svg/desingsystem.svg"
/>             
```

Opciones  **Admin y Components**

```
<jmoordbcoreui:menu 
    value="Admin"
    min-value="A" 
    href="../dashboard/admin.xhtml"
    typeIcon="svg"
     svgName="images/svg/admin.svg"                                    
/>        


 <jmoordbcoreui:menu 
     value="Components" 
     min-value="C"
     href="https://templates.iqonic.design/hope-ui/html/dist/#accordion"
     typeIcon="svg"
     svgName="images/svg/components.svg"                                    
/>           
```

## Menu Grupo

Generalmente se usa para agrupar o separar elementos creando un texto de división.

Por ejemplo: **Home, Pages, Elements**




```

<jmoordbcoreui:menuGroup normalLabel="Home" collapsedLabel="-"/>

<jmoordbcoreui:menuGroup normalLabel="Pages" collapsedLabel="-"/>

<jmoordbcoreui:menuGroup normalLabel="Elements" collapsedLabel="-"/> 



```
