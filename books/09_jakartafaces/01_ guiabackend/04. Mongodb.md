# 04. MongoDB


## Cambiar Nombre de la base de datos


 Cambiar el nombre a la base de datos

Pasos:

1. Cree un backup de la base de datos

```shell

mongodump --archive=accreditation.gz --gzip --db=accreditation

```

2. Restaure la base de datos usando

* --nsInclude para indicar las colecciones a transferir
* --nsFrom: Para indicar desde cual base de  datos
* --nsTo: Nombre de la nueva base de datos


```shell

mongorestore --gzip --archive=accreditation.gz --nsInclude='*.*' --nsFrom='accreditation.*' --nsTo='vencotdb.*'


```

3. Contamos con la nueva base de datos **vencotdb**


4. Utilice un GUI o desde consola para trabajar con la coleccion applicative, debe contener un solo registro con la configuración de la aplicación.

```shell

mongosh

use vencotdb

show collections

```

5. Eliminar los documentos existentes

