# Progreso

En JettraStorePolice3D los objetos siguientes que corresponden a 
Personas , Edificios,Camiones, Perros deben corresponder a la cantidad de objetos en tiempo real que esta procesando el servidor que tiene JettraStore.


Añadir un panel que permita gestionar los usuarios de JettraStore es decir crear, editar, eliminar, asignar roles y asignar roles a las bases de datos
a los que tendra acceso.


Añadir un panel en la base de datos que permita ver el contenido de objetos por cada engine que soporta la base de datos
por ejemplo al seleccionar la base de datos example_factura_db y dar clic derecho se muestra el panel con un abril con los
engine (document, graph, vector, java record, y los demas) y cada engine puede expandirse para mostrar los registros paginados.
