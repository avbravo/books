# PROGRESO

Modifique la forma interna de trabajar JettraStore
en lugar de tomar el path del archivo database.properties
#jettra.storage.path = /var/jettra/data
jettra.storage.path = ~/jettra/data

esta propiedad no se usara mas


Use la informacion del archivo jettra.config
y añade una propiedad nueva llamada 
cluster.node.id= <cluster.node.1.id>
Esta propiedad se asigna  el valor de cluster.node.1.id o cluster.node.2.id o cluster.node.3.id

para indicar en cual nodo se encuentra es decir que la persona esta ejecutando desde el nodo1, 
nodo 2 o nodo 3.

y en base a ese valor
verifica el path para almacenar los datos del nodo indicado ya sea para node.1, node.2 o node.3
cluster.node.1.storage.path = ~/jettra/node-01/data

cluster.node.2.storage.path = ~/jettra/node-02/data

cluster.node.3.storage.path = ~/jettra/node-03/data
