En el proyecto JettraStoreShell 

cree un archivo install.sh que se encarga de crear el directorio copiar el jar y el archivo microprofile-config.properties listo para ser ejecutado en el directorio ~/jettrastoreshell. Tambien debe copiar el archivo start.sh
Tambien crea el archivo start.sh que se encarga de ejecutar JettraStoreShell con parametros configurados en el archivo microprofile-config.properties.
Actualiza el archivo Dockerfile y el archivo docker-compose.yml
