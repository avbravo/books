### **¿Qué es un Reverse Proxy?**

Un **reverse proxy** es un servidor intermediario que actúa como punto de entrada para las solicitudes HTTP/HTTPS que llegan a una aplicación o conjunto de aplicaciones. A diferencia de un **forward proxy**, que se utiliza para proteger clientes (usuarios), el reverse proxy se utiliza para proteger y gestionar servidores.

#### Funciones principales de un reverse proxy:
1. **Balanceo de carga**: Distribuye las solicitudes entre varios servidores backend para mejorar la disponibilidad y el rendimiento.
2. **Seguridad**: Oculta la infraestructura interna del servidor, mostrando solo el reverse proxy al exterior.
3. **SSL/TLS terminación**: Maneja la encriptación/desencriptación HTTPS, reduciendo la carga del servidor backend.
4. **Compresión y caché**: Mejora el rendimiento comprimiendo respuestas y almacenando contenido en caché.
5. **Redirección**: Permite redirigir solicitudes a diferentes servicios según reglas configuradas.

---

### **Cómo funciona un Reverse Proxy**

El flujo básico de funcionamiento es el siguiente:
1. Un cliente (por ejemplo, un navegador) envía una solicitud HTTP/HTTPS a la dirección del reverse proxy.
2. El reverse proxy recibe la solicitud y, según su configuración, decide a qué servidor backend debe reenviarla.
3. El servidor backend procesa la solicitud y devuelve una respuesta al reverse proxy.
4. El reverse proxy envía la respuesta al cliente.

En este proceso, el cliente no tiene conocimiento directo de los servidores backend; solo interactúa con el reverse proxy.

### **Configuración de un Reverse Proxy para una Aplicación Eclipse MicroProfile con Payara Micro**

Para configurar un reverse proxy para una aplicación basada en **Eclipse MicroProfile** desplegada en **Payara Micro**, puedes usar herramientas populares como **Nginx** o **Apache HTTP Server**. Aquí te explico cómo hacerlo con **Nginx**, que es una opción ampliamente utilizada por su simplicidad y rendimiento.

---

#### **Paso 1: Instalar Nginx**
Si no tienes Nginx instalado, puedes instalarlo siguiendo estos pasos:

- En Ubuntu/Debian:
  ```bash
  sudo apt update
  sudo apt install nginx
  ```

- En CentOS/RHEL:
  ```bash
  sudo yum install epel-release
  sudo yum install nginx
  ```

Una vez instalado, inicia y habilita el servicio:
```bash
sudo systemctl start nginx
sudo systemctl enable nginx
```

---

#### **Paso 2: Configurar Nginx como Reverse Proxy**

Edita el archivo de configuración de Nginx. Por defecto, está ubicado en `/etc/nginx/nginx.conf` o `/etc/nginx/sites-available/default`.

Agrega una configuración como la siguiente:

```nginx
server {
    listen 80;
    server_name tu-dominio.com;

    location / {
        proxy_pass http://localhost:8080;  # Dirección donde corre Payara Micro
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

#### Explicación de la configuración:
- `listen 80`: Indica que Nginx escuchará en el puerto 80 (HTTP).
- `server_name`: Especifica el dominio o dirección IP a la que responderá Nginx.
- `proxy_pass`: Indica la dirección del servidor backend (en este caso, Payara Micro).
- `proxy_set_header`: Configura encabezados adicionales para garantizar que el backend reciba información correcta sobre el cliente original.

---

#### **Paso 3: Reiniciar Nginx**
Guarda el archivo de configuración y reinicia Nginx para aplicar los cambios:
```bash
sudo nginx -t  # Verifica que la configuración sea válida
sudo systemctl restart nginx
```

---

#### **Paso 4: Desplegar la Aplicación en Payara Micro**

1. Asegúrate de que tu aplicación Eclipse MicroProfile esté empaquetada como un archivo WAR.
2. Inicia Payara Micro con el siguiente comando:
   ```bash
   java -jar payara-micro.jar --deploy tu-aplicacion.war
   ```
   Esto iniciará Payara Micro en el puerto 8080 (por defecto).

3. Accede a tu aplicación a través del reverse proxy. Por ejemplo, si configuraste Nginx para escuchar en `http://tu-dominio.com`, podrás acceder a tu aplicación en esa URL.

---

#### **Opcional: Configurar SSL/TLS en Nginx**

Para habilitar HTTPS, necesitas un certificado SSL. Puedes obtener uno gratuito de Let's Encrypt usando Certbot:

1. Instala Certbot:
   ```bash
   sudo apt install certbot python3-certbot-nginx
   ```

2. Obtén un certificado:
   ```bash
   sudo certbot --nginx -d tu-dominio.com
   ```

3. Certbot modificará automáticamente la configuración de Nginx para usar HTTPS.
