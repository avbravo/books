Es posible que te refieras a **Keycloak** (no "keyloach"), un sistema de gestión de identidad y acceso (IAM) de código abierto. Si es así, aquí te explico cómo integrar **Keycloak** en una aplicación Java usando **Payara Micro** y **Eclipse IDE** (asumo que "Eclipse Gélido" es una confusión con el IDE Eclipse).

---

### **Pasos para Integrar Keycloak en una aplicación con Payara Micro y Eclipse**

#### 1. **Configurar Keycloak**
   - **Descarga y ejecuta Keycloak**:
     - Descarga desde [keycloak.org](https://www.keycloak.org/).
     - Ejecuta en modo desarrollo: `bin/kc.sh start-dev` (Linux/Mac) o `bin\kc.bat start-dev` (Windows).

   - **Crear un Realm y un Cliente**:
     1. Accede al admin console: `http://localhost:8080`.
     2. Crea un nuevo "Realm" (ej: `myrealm`).
     3. Crea un cliente (ej: `myapp-client`) con protocolo `openid-connect`.
     4. Configura el cliente:
        - **Valid Redirect URIs**: `http://localhost:8080/*` (ajusta según tu app).
        - **Web Origins**: `+`.

   - **Crear Usuarios y Roles**:
     - En la pestaña "Users", crea un usuario (ej: `user1`).
     - En "Roles", crea roles (ej: `user`, `admin`).
     - Asigna roles al usuario.

---

#### 2. **Configurar el Proyecto en Eclipse**
   - **Estructura del Proyecto**:
     - Asegúrate de tener un proyecto Java EE/Web existente.
     - Ejemplo de dependencia Maven para Keycloak (en `pom.xml`):

     ```xml
     <dependency>
         <groupId>org.keycloak</groupId>
         <artifactId>keycloak-adapter-core</artifactId>
         <version>21.1.2</version> <!-- Usa la versión compatible -->
     </dependency>
     ```

---

#### 3. **Configurar Seguridad en la Aplicación**
   - **Archivo `web.xml`**:
     Define los roles y restricciones de seguridad.

     ```xml
     <security-constraint>
         <web-resource-collection>
             <web-resource-name>Secured Area</web-resource-name>
             <url-pattern>/secured/*</url-pattern>
         </web-resource-collection>
         <auth-constraint>
             <role-name>user</role-name>
         </auth-constraint>
     </security-constraint>

     <login-config>
         <auth-method>KEYCLOAK</auth-method>
     </login-config>

     <security-role>
         <role-name>user</role-name>
     </security-role>
     ```

   - **Archivo `keycloak.json`**:
     Colócalo en `src/main/webapp/WEB-INF/`:

     ```json
     {
         "realm": "myrealm",
         "auth-server-url": "http://localhost:8080",
         "ssl-required": "external",
         "resource": "myapp-client",
         "public-client": true,
         "confidential-port": 0
     }
     ```

---

#### 4. **Codificar un Endpoint Seguro**
   - **Ejemplo de Servlet**:

     ```java
     import javax.annotation.security.RolesAllowed;
     import javax.servlet.annotation.WebServlet;
     import javax.servlet.http.HttpServlet;

     @WebServlet("/secured/user")
     @RolesAllowed("user")
     public class SecuredServlet extends HttpServlet {
         protected void doGet(HttpServletRequest req, HttpServletResponse res) {
             res.getWriter().write("Acceso permitido para usuarios!");
         }
     }
     ```

---

#### 5. **Desplegar en Payara Micro**
   - **Empaqueta la Aplicación**:
     - Genera un WAR: `mvn clean package`.

   - **Ejecuta Payara Micro**:
     ```bash
     java -jar payara-micro.jar --deploy target/mi-app.war
     ```

   - **Accede a la Aplicación**:
     - Abre `http://localhost:8080/mi-app/secured/user`.
     - Serás redirigido a Keycloak para autenticarte.

---

#### 6. **Configurar Eclipse**
   - **Integración con Payara Micro**:
     1. Instala el plugin "Payara Tools" en Eclipse.
     2. Configura un servidor Payara Micro en Eclipse.
     3. Despliega la aplicación desde el IDE.

---

### **Ejemplo de Flujo**
1. El usuario accede a `/secured/user`.
2. Keycloak redirige al login.
3. Tras autenticarse, Keycloak emite un token JWT.
4. La aplicación valida el token y permite el acceso si el usuario tiene el rol `user`.

### **Notas**
- Asegúrate de que Payara Micro tenga acceso a las dependencias de Keycloak.
- Configura CORS en Keycloak si es necesario.
