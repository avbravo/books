### **1. Configuración del Cliente**

El cliente debe obtener un token JWT de Keycloak enviando las credenciales del usuario (nombre de usuario y contraseña) al endpoint `/protocol/openid-connect/token` de Keycloak. Aquí está el código completo para implementar esta funcionalidad.

### **2. Código del Cliente Jakarta Faces**

#### **a. Clase para Obtener el Token**
Crea una clase que maneje la solicitud HTTP POST a Keycloak para obtener el token.

```java
package com.example.frontend;

import jakarta.enterprise.context.SessionScoped;
import jakarta.ws.rs.client.ClientBuilder;
import jakarta.ws.rs.client.Entity;
import jakarta.ws.rs.core.Form;
import jakarta.ws.rs.core.MediaType;
import jakarta.ws.rs.core.Response;

import java.io.Serializable;

@SessionScoped
public class KeycloakTokenService implements Serializable {

    private static final String KEYCLOAK_AUTH_URL = "http://localhost:8080/auth/realms/microprofile-realm/protocol/openid-connect/token";
    private static final String CLIENT_ID = "frontend-client";
    private static final String CLIENT_SECRET = "your-client-secret"; // Opcional si es público

    private String accessToken;

    public String getAccessToken() {
        return accessToken;
    }

    public void login(String username, String password) {
        Form form = new Form();
        form.param("grant_type", "password")
            .param("client_id", CLIENT_ID)
            .param("username", username)
            .param("password", password);

        if (CLIENT_SECRET != null && !CLIENT_SECRET.isEmpty()) {
            form.param("client_secret", CLIENT_SECRET);
        }

        Response response = ClientBuilder.newClient()
                .target(KEYCLOAK_AUTH_URL)
                .request(MediaType.APPLICATION_JSON)
                .post(Entity.entity(form, MediaType.APPLICATION_FORM_URLENCODED));

        if (response.getStatus() == 200) {
            String jsonResponse = response.readEntity(String.class);
            this.accessToken = parseAccessToken(jsonResponse);
        } else {
            throw new RuntimeException("Error al obtener el token: " + response.readEntity(String.class));
        }
    }

    private String parseAccessToken(String jsonResponse) {
        // Parsea el JSON manualmente o usa una librería como Jackson/Gson
        int start = jsonResponse.indexOf("\"access_token\":\"") + "\"access_token\":\"".length();
        int end = jsonResponse.indexOf("\"", start);
        return jsonResponse.substring(start, end);
    }
}
```

#### **b. Managed Bean para el Login**
Crea un `ManagedBean` que permita al usuario iniciar sesión y almacenar el token.

```java
package com.example.frontend;

import jakarta.faces.bean.ManagedBean;
import jakarta.faces.bean.SessionScoped;

@ManagedBean
@SessionScoped
public class LoginBean {

    private String username;
    private String password;
    private String message;

    private final KeycloakTokenService tokenService = new KeycloakTokenService();

    public String getUsername() {
        return username;
    }

    public void setUsername(String username) {
        this.username = username;
    }

    public String getPassword() {
        return password;
    }

    public void setPassword(String password) {
        this.password = password;
    }

    public String getMessage() {
        return message;
    }

    public String login() {
        try {
            tokenService.login(username, password);
            message = "Login successful!";
            return "success"; // Redirige a otra página
        } catch (Exception e) {
            message = "Login failed: " + e.getMessage();
            return "failure";
        }
    }

    public String callBackend() {
        RestClient client = new RestClient(tokenService.getAccessToken());
        return client.callBackend("user");
    }
}
```

#### **d. Modificación del Cliente REST**
Actualiza el cliente REST para que utilice el token obtenido de Keycloak.

```java
package com.example.frontend;

import jakarta.ws.rs.client.ClientBuilder;
import jakarta.ws.rs.core.Response;

public class RestClient {

    private final String token;

    public RestClient(String token) {
        this.token = token;
    }

    public String callBackend(String endpoint) {
        Response response = ClientBuilder.newClient()
                .target("http://localhost:8080/api/" + endpoint)
                .request()
                .header("Authorization", "Bearer " + token)
                .get();

        return response.readEntity(String.class);
    }
}
```

### **3. Flujo Completo**

1. El usuario ingresa sus credenciales en la página `login.xhtml`.
2. El `ManagedBean` (`LoginBean`) llama al servicio `KeycloakTokenService` para obtener un token JWT.
3. El token se almacena en la sesión y se utiliza para comunicarse con el backend MicroProfile.
4. El backend MicroProfile valida el token JWT y verifica los roles antes de responder.

---

### **4. Ejemplo de Uso**

#### **a. Iniciar Sesión**
- El usuario ingresa `username` y `password` en la página de login.
- Si las credenciales son válidas, Keycloak devuelve un token JWT.

#### **b. Llamar al Backend**
- Una vez autenticado, el usuario puede llamar a los endpoints protegidos del backend MicroProfile utilizando el token JWT.

#### **c. Respuesta del Backend**
- El backend verifica el token y devuelve una respuesta según los roles del usuario.
